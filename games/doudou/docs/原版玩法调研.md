## 一、核心循环

```
准备（时间冻结：拖人/合成/刷新）
  → 开战（自动攻击，关键波次可长按放主动技能）
  → 清波 / 漏怪扣血
  → 过关三选一强化（攻击/攻速/金币等）
  → 回准备，金币产出、放下一个角色/面板
  → 重复，直到通关或基地血空
```

`[官方][评测]` 确认：合并（merge）+ 塔防 + 背包格子 + 100+ 关卡 + 5+ 休闲小游戏。

## 三、和原版对齐的关键差异（复刻清单）

按「先抄」排序，前四条是原版有、我们没有的：

1. **单位有生命、会被打死**。原版僵尸会围上来打人，前排角色会死，所以才有「肉盾/医生/工程师」的配置意义。我们现在的敌人只会走向基地，单位永远安全——整个职责体系建立不起来就是卡在这。
2. **敌人会攻击单位，不只会走向基地**。
3. **兵种分工**：医务兵（治疗）、工程师（护甲恢复）、战争顾问（产银币）、鼓号队（充能/加速）、地雷专家（预放陷阱）、激光射手（蓄力穿透）、迫击炮手（范围+重伤）、轰炸指挥员（眩晕）。
4. **透明面板 = 格子扩展道具**，不是「清波自动解锁」。
5. **主动技能**：关键波次长按，耗能量。
6. **BOSS 生成**：土豆巨人（高防）、刺客（高机动）。
7. **局外**：碎片升星 + 章节解锁。

我们现有 `TUNE`（`squad.js:69`）可以沿用，复刻时按「一局 3~5 分钟 / 15 波」的节奏调。

## 六、专精：按兵种分化（2026-11-20 调研）

**原版结构** `[攻略][推断]`

- 多个下载站的角色页都保留同一模板：「可激活特性：等级 1 / 2 / 3 / 4 / 5」，
  但正文值没被爬到（表格是空的）。能确认的是**原版每个兵种都有一条 1–5 级特性链**，
  不是全兵种共用一套（[18touch](https://www.18touch.com/game/210706.html)、
  [minecraftxz](https://www.minecraftxz.com/app/317691.html)、
  [juxia](https://www.juxia.com/sjwy/youxi-683323.html)）。
- 招牌特性按兵种走：三星狙击手蓄力后可穿透、霰弹枪兵群体攻击 + 击退、
  迫击炮范围伤害 + 重伤、鼓号队充能、顾问产银币 / 省银币
  （[快吧](https://www.kuai8.com/shouyou/972088.html)、
  [18touch](https://www.18touch.com/game/210706.html)）。
- B 站无尽阵型视频也按兵种卡节点：鼓号兵「至少 8 个 5 级」才能维持火力
  （[BV1tbw1eBEe7](https://www.bilibili.com/video/BV1tbw1eBEe7)）——
  5 级是原版的实用断点，和我们现有的 Lv5 节点对得上。

**同类成熟解法** `[参考]`

- Rush Royale：每张卡有专属天赋树，天赋在该卡等级节点解锁，效果只强化这张卡
  本来的动词（例：Bruiser 的三叶草叠伤害 / 狂暴攻速）
  （[alucare](https://www.alucare.fr/cogneur/)、
  [官方天赋节](https://rushroyale.my.games/tr/news/50/eobdeiteu-281e-osin-geos-eul-hwan-yeonghabnida)）。
- 合成塔防《末日铁路防御》：初级合成给同类型单位附加击退 / 辐射，进阶合成才换形态——
  **升级只改已有行为，不另起系统**（[9game](https://www.9game.cn/news/12215182.html)）。

**结论（照抄结构，不抄数值）**

- 结构：每兵种 4 个节点，等级 5 / 7 / 9 / 10（和合成上限、现有面板对齐）。
- 效果：只从现有 effect 管线里选（rate / range / dmg / pellets / pierce / splash /
  heal / armor / coin / haste），不新增战斗系统。
- 数值：原版具体值拿不到，自定——**别标成「原版数值」**。

## 七、三选一词条（2026-11-20 晚调研）

- 原版：三选一是**过关 / 升级给 Buff 或资源**（[diyiyou](https://m.diyiyou.com/xiazai/394965.html)）；
  主人实测更像「杀怪升级才弹」，以主人体验为准——结构按升级走，不按波数。
- Vampire Survivors：升级暂停，给 3~4 个选项；**不重复**；满级项不再出现；
  选项来自按稀有度加权的池（[Level up](https://vampire-survivors.fandom.com/wiki/Level_up)、
  [系统拆解](https://teemo.dev/game-design/vampire-survivors/systems/replayability-and-randomness/)）。
- 国内远征三选一：池里登记「效果 / 稀有度 / 权重」，抽三张且互不重复，只在本次远征生效
  （[玩法策划](https://www.chuan2.cn/a/art260922818d68.html)）。

**结论（我们自己的词条池）**

- 三档：普通 Lv1 起 / 稀有 Lv5 起 / 史诗 Lv10 起；权重抽、同兵种同属性不重复。
- 效果只复用现有属性：伤害 / 攻速 / 射程 / 生命 / 弹道 / 穿透 / 溅射 / 治疗 / 减伤 / 产币 / 攻速光环 / 金币。
- 辅助位只出自己光环的词条，避免「给医生抽伤害」这种废卡。
- 具体数值自定，不标「原版数值」。

## 八、结论

原版的「核」是：**背包格子 + 合成 + 单位会死 + 分工**。

我们现在有前两个，缺后两个。**先补「单位会死 + 敌人会打人」，分工才有意义**——这是 1:1 复刻的第一步，也是整个职责体系的地基。
