## 一、五条基石（不可动摇）

| # | 基石 | 含义 |
|---|---|---|
| 1 | **45° 俯视** | 正交相机，固定角度，不旋转、不平视 |
| 2 | **2.5D 等距 + 童话风** | 斜俯视的可信世界；**休闲、童话、轻松**，不是传奇写实 |
| 3 | **玩法 / 数值不动** | 战斗、掉落、商店、任务、升级曲线一行不改 |
| 4 | **可信感** | 投影一致、有影子、一套色板、有层次、不违和。**不是物理真实光照** |
| 5 | **Three.js** | 正交相机 + 2D 精灵 + 菱形瓦片，纯静态网页，双击能跑 |

**基石之上的都可以谈；基石本身不再讨论。**

---

## 二、由基石推出的结论

| # | 结论 | 说明 |
|---|---|---|
| 1 | **角色用 2D 等距精灵，3 头身** | 不建模、不做 3D 低模；Q 版比例（头占身高 1/3），不是 2 头身 |
| 2 | **光照靠烘焙，不靠实时光源** | 每个资产自带方向一致的光影；统一调色板收敛 |
| 3 | **相机固定 45° 正交** | 不旋转，避免破绽 |
| 4 | **地面用统一菱形瓦片** | 不用平铺照片纹理（现在的问题之一） |
| 5 | **AI 生图恢复为主要手段** | 出单件等距资产；代码负责抠底、锚点、拼装 |
| 6 | **2D Canvas 版冻结** | 只保留回退，不再开发 |
| 7 | **连续世界 / 词缀 / 多区域后置** | 先把一屏做对 |

> 哪条结论不同意就改哪条；基石不动，推论可调。

## 三·五、工作方式（反盲盒）

> **每一轮：先小场景，后主城；一次只改一个变量；审美靠参数，不靠描述。**

1. **小样本先行** —— 5×5 格小场景（1 房 1 人 1 树），10 分钟出图；小场景过了才铺主城
2. **一次一变量** —— 一轮只改一件事，验收通过再开下一轮
3. **参数化** —— 能用滑杆调的，不写进描述；调完把数值抄回规格
4. **不 commit** —— Cursor 每轮只交截图 + 测试结果，由主人拍板

**轮次表：**

| 轮 | 只改 | 验收 |
|---|---|---|
| 0 | 搭最小测试场景（能显示） | 能跑、能截图 |
| 1 | 瓦片无缝 | 无黑缝、无棋盘格 |
| 2 | 接触阴影 | 每个立地物体脚下有影子 |
| 3 | 排序 | 走到房子后面会被挡住 |
| 4 | 色板 | 明亮暖色，不荧光 |
| 5 | Q 版建筑 + 3 头身角色 | 比例协调，不像两个游戏 |
| 6 | 铺主城 | 十项验收全过 |
