# 守护豆豆 · 小队模式（v0.9 · 40/60 布局 + 倍速 + 专精面板 + 伤害数字）

参考玩法：微信小游戏《小小生存队》。**只借了结构，没有抄内容**（没有碎片、宝箱、广告位）。

入口：`games/doudou/index.html` 右上角「小队模式」；直接打开 `squad.html` 也行。

## 游戏目标（2026-11-20 主人定，最高优先级）

**先照抄，再创新。**

1. **照抄对象**：《小小生存队》的核心循环——背包格子 + 合成 + 单位会死 + 分工。
2. **照抄阶段不做「我觉得更好」的改动**：操作、刷新节奏、波次结构、稀有度色阶，先对齐原版；
   要改，先写进本文档「待验证的创新」一节，等照抄验收通过再动。
3. **创新只允许在照抄完成后**，并且必须能回答「原版为什么没这么做」。

## 结构

```
准备（时间冻结）→ 3 个待命位（和战场同一套画法）→ 点/拖进格 → 开战 →
清场 → 免费自动刷一次 + 三选一强化 → 回准备。每关 20 波；**漏一个怪就输**（没有基地血量）。
通一关 → 点一下进下一关（进度存 localStorage）。共 10 关。
```

**竖屏布局（2026-11-20 定版，720×1440 逻辑，1:2）**：

```
y 0..960      上 2/3：一整块战场（以后贴背景图只换这一块；顶栏叠在最上面）
y 960..1030   下 1/3：顶部金币总额
y 1028..1228  3 个待命位（190×200，不是卡片；单位按战场画法站进去，框最长边适配 160）
y 1248..1358  刷新 / 开战 大按钮（110 高）
y 1380..1440  底部（← 库 / 经典 入口）
```

- **格子区占宽 40%、街道 60%**（2026-11-20 主人定，好算）：5×5 格、格 56、宽 280；
  格子区在战场里垂直居中（y 340..620）。单位直径约 38、敌人 18、小 BOSS 32、大 BOSS 44。
- **5×5 = 25 格默认全开**：原版也是这样；前期卡人的是金币（刷不起），不是格子。
- **待命区不是卡片**：3 个待命位，单位用**和战场完全相同的 `drawUnit`** 画（稀有度框 + 角标 + 枪管），
  按占格把框的最长边适配到 160（1×1 和 2×2 看着一样饱满）。占格看框形状，等级看框色 + 角标。
- 交战中待命区换成一条状态带（波次 + 场上敌人数），不放空位。
- 格子紧挨着画、不留缝；空格用棋盘色差分格；战场中段铺一条横向街道，格子压在路上。
- 顶栏右侧有 **倍速按钮 ×1 / ×2 / ×3**（点一下循环，只在战斗阶段生效，准备阶段时间照旧冻结）。
- 手机竖着拿：`#stage` 宽 `min(100vw, 100dvh*0.5)`、高 `min(100dvh, 100vw*2)`，基本铺满。

## 金币：只有三个来源（2026-11-20 主人定）

1. **战争顾问上场**：每个顾问每秒 +0.35（**只在战斗阶段结算**，准备阶段时间冻结，一分钱不涨）。
2. **清一波**：`8 + 波数×2`。
3. **三选一补给**：抽到「获得 30 金币」。

没有基础每秒收入、没有打怪掉钱、没有开局自动涨——`TUNE.coinPerSec` 已删除。

## 每波结束自动免费刷一次

`settleWave()` 里 `G.wave++` 后调 `rollBench()`：待命区直接补 3 个新候选（自动合成照常），
并把付费刷新计数归零（下一刷从 10 起价）。作用是白送一次 + 提醒玩家「这里可以刷新」。

## 战斗表现（2026-11-20 本轮）

- **伤害数字**：子弹命中就飘伤害值（暖白；3 星以上金色、5 星更大），溅射也会飘；
  总数限流 48 条，防止割草时刷屏。
- **弹道扫掠判定**：子弹按「上一帧 → 这一帧」的线段判定，不再只看落点。
  小怪 r=9、子弹一帧能飞十几像素，点判定会直接穿过去——**这就是「只有子弹没伤害」的根因**。
- **清波清场**：`settleWave()` 清空 `bullets / bits / floats / rings / enemies`，
  回准备时不留上一波的子弹和尸体。
- **战斗倍速 ×1/×2/×3**：`frame()` 里在战斗中多跑几步固定步长（不是把 dt 乘大），
  弹道和碰撞不会因为加速而穿透；准备阶段永远 1 步。

### 波次与 BOSS（2026-11-20）

- **每波敌人数** = `6 + 波数 × 2.4`（第 20 波 54 个），个体更脆 → 割草感。
- **小 BOSS** 压第 **5 / 10 / 15** 波末尾（血 ×28、速 ×0.75、攻 ×1.5、r=16）；
  **大 BOSS** 压第 **20** 波末尾（血 ×60、速 ×0.6、攻 ×2.2、r=22）。
- **没有基地血量**：不管小兵还是 BOSS，漏到基地线当场判负——BOSS 也只是一只更难打的怪。
- BOSS 最后出场、不占小兵名额；进度条上 5/10/15 有紫三角、20 有红三角。

### 生命：单位会死，敌人会围上来打人

- 每个单位有血，**星级每升 1 星 +180% 血**，合成时回满。
- 敌人压到某个单位的格子右侧就**停下来啃它**（每秒 1 口），啃死之后继续走。
- 单位死了就从格子上消失（**不退回待命区**），战斗里也不能补——所以前排真的会空。
- 单位头顶有血条（受伤才显示，绿→黄→红），敌人啃人时身体前扑、带抓痕。
- 医生给队友回血但**不自奶**（否则一群医生会互相回成打不死的铁王八，模拟里真踩过）。

### 养成：等级卡住合成上限 + 专精里程碑

- 每个兵种有一个**跨局保留**的等级（存 `doudou.squad.lv`，初始 3 级）：
  **合成上限 = 兵种等级**（3 级只能合到 A 档 3 星），等级每升 1 级基础攻击 +12%。
- **专精里程碑**（所有兵种同一套，`squad-data.js` 的 `MASTERY`）：
  **Lv5 攻速 +10% · Lv7 射程 +10% · Lv9 伤害 +20% · Lv10 弹道 +1**。真实作用于战斗。
- 升级花**局内金币**（每局重新赚），等级留着；上限 10 级，花费 `60 × 当前等级`。
- **养成面板**：全宽 10 行，每行显示 当前 Lv / 可合星数 / 当前攻击力 / 兵种特性 /
  已解锁专精 / 下一专精 / 升级费用；锁定兵种显示第几关解锁。顶部写明「每级 +12%」和四条专精。

## 操作（对齐原版）

- **点按**：点待命位 / 场上单位选中（脚下黄圈）→ 点空地/空格放过去；点同兵种同星 → 合成。
  点按和拖拽走**同一条落点逻辑**（`drop()`），大单位自动找最近的合法位置。
- **拖拽**：拖单位 → 格子放人；拖格子 → 换位 / 同款合成；**场上单位拖回待命位可以回收**（空位放，占用的位试合成）。
- **待命区是合成中转站，不保留**：场上单位拖回来自动合成；合完再拖上场。**开战和刷新时清空**。
- **刷新**：换掉 3 个候选，价格每次 +5（每波重置）；**每波结束免费刷一次**。
- 拖大单位有 **w×h 预览框**：绿=能放 / 金=能合 / 红=放不下。
- **倍速**：顶栏 ×1 / ×2 / ×3，点一下循环；只在战斗阶段生效，准备阶段时间冻结。
- 鼠标和触摸都走 Pointer Events，多指只认第一根；点击/拖拽用移动距离 10 CSS px 区分。
