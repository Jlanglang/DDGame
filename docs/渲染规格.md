# 渲染规格 · 2.5D 等距童话感

> **2026-10-28 定案**：主人要的是「**休闲、童话、轻松**」，**不是传奇写实**。
> 玩法是刷宝 ARPG（不动），画面走童话。
> 本文从「3D 物理真实」→「2.5D 等距可信感」→ 现定为「**2.5D 等距童话感**」。
>
> 配套：`docs/STATUS.md`（项目状态与验收）

---

## 〇、一句话

> **可信感 = 投影一致 + 有影子 + 一套色板 + 有层次。**
> **童话感 = 比例圆润 + 颜色明快 + 细节柔和。**

---

## 〇·二、风格定位（最重要，先定这个）

| 项 | 方向 |
|---|---|
| 气质 | **休闲、童话、轻松** |
| 角色 | **3 头身**（头约占身高 1/3），圆润、表情清楚 |
| 建筑 | **Q 版**：矮胖、屋顶大、门洞圆、颜色明快 |
| 地面 | 卡通手绘瓦片，饱和、温暖 |
| 色板 | **明亮暖色为主**（奶油、暖黄、草绿、砖红），不要暗黑、不要灰调 |
| 阴影 | 柔和、浅，不要浓重 |
| 线 | 柔和的深色描边（不要纯黑硬边） |
| 参考 | 牧场物语 / Fantasy Life / 开罗游戏 |

> **关键：角色和建筑必须是同一个童话比例。**
> 3 头身的人站在 6 头身的写实房子旁，还是「两个游戏」——只是换了个方向的不协调。

---

## 〇·三、体型阶梯（头身比 = 强度语言）

**全世界的生物都用同一套头身比阶梯，玩家一眼看出强弱。**

| 头身 | 视觉印象 | 暗黑传奇对应 |
|---|---|---|
| **1 头身** | 团子、几乎只有头 | 史莱姆、小虫、蘑菇怪 |
| **1.5~2 头身** | 小动物，头大身小 | 鸡、野狗、野猪、蝙蝠 |
| **3 头身** | 标准人形（**玩家基线**） | 豆豆玩家、NPC、稻草人、山贼 |
| **4 头身** | 高大、精英感 | 石魔、恶魔、守卫、精英怪 |
| **5 头身** | 巨物、压迫感 | 巨型稻草人王、BOSS |

**三条原则：**

1. **越强越大**——体型是等级之外的第二个强度信号
2. **萌化不等于弱化**——5 头身 BOSS 依然圆润可爱，但**体积压人**，反差就是压迫感
3. **同屏要有梯度**——不要所有怪都 3 头身，一个场景里至少两种体型

**技术注意：**

- 每个单位加一个 `heads` 参数（1 / 1.5 / 2 / 3 / 4 / 5），渲染按比例缩放精灵
- **碰撞体积和视觉大小解耦**——1 头身的史莱姆视觉小，但碰撞不能也缩到看不见
- 阴影按体型缩放，但**方向和不透明度统一**
- 5 头身 BOSS 在 45° 俯视下会挡后面，站位要留空，或者给 BOSS 单独留一片场地
- 1 头身单位太小，要保证**可点选、可看清朝向**（建议最小不低于 24px）

## 一、投影（错这条全错）

**默认相机是 mir 俯视透视**（详见 `docs/STATUS.md`）：yaw0° / pitch55° / fov32 / zoom1.70（竖向≈20 格）。
旧等距用 `?cam=iso` 仅作对比。立牌角度仍待「mir 立牌」轮对齐，本轮只改地面。

| 项 | 规格 |
|---|---|
| 投影 | **mir 俯视透视**（默认）；贴图为俯视正方形 |
| 相机 | 固定角度，**不旋转、不平视** |
| 地面 | 俯视方格瓦片铺在水平面；近大远小交给相机，不是菱形手绘、不是照片纹理 |
| 角色 | 立牌精灵（能看见头顶 + 正面）；角度对齐 mir（待立牌轮） |
| 建筑 | 立牌（能看见屋顶），**Q 版矮胖**（待立牌轮） |
| 道具 | 同上 |

**判定方法（地面）**：石板边与屏幕横/纵大致对齐（横平纵深），板面左上亮、右下暗。

## 二、统一色板与烘焙光

| 项 | 规格 |
|---|---|
| 色板 | 全局 **12~16 色**，**明亮暖色** |
| 光源方向 | **统一左上**（选定不改） |
| 光影 | 每个资产自带烘焙光影，**方向必须一致** |
| 色温 | 全局偏暖 |
| 对比度 | 中等偏低（童话不要强对比） |
| 饱和度 | 中高（童话可以鲜一点） |

**参考色板方向**（不是死值，是调性）：

```
亮底     #F7EEDB   （奶油）
暖黄     #F2C46B
草绿     #8CC26A
砖红     #C9604F
天蓝     #7FB6D9
木棕     #9A6B47
深棕线   #3B2F26   （描边/阴影，不用纯黑）
```

**出图后必做**：

1. 映射到统一色板
2. 统一色温（偏暖）与对比度
3. 统一明度区间

**AI 出图的「画风不统一」，80% 靠这一层解决。**

## 三、接触阴影（落地，性价比最高）

**没有影子的物体，一定像贴纸。**

| 项 | 规格 |
|---|---|
| 形状 | 椭圆（不是圆） |
| 尺寸 | 宽 ≈ 物体宽 × 0.8，高 ≈ 宽 × 0.35 |
| 颜色 | 深棕（`#3B2F26`），**不要纯黑** |
| 不透明度 | 0.25 ~ 0.40（童话要浅一点） |
| 位置 | 物体脚底中心，**向右下偏移 2~4px** |
| 边缘 | 软边（径向渐变） |

**每个立在地面上的东西都要有**：角色、怪物、NPC、建筑、树、摊位、石头。

## 四、地面瓦片（最容易做砸）

**禁止一整张平铺照片当草地。**

### 4.1 硬规则：不许有黑缝

**这是等距地面最常见的失败：每个菱形单独描边，整张图变成棋盘格。**

| 禁止 | 结果 |
|---|---|
| 瓦片图自带黑色描边 | 拼起来就是网格线 |
| 瓦片之间留空隙 | 露出底色，像水泥缝 |
| 每个菱形画独立边框 | 格子感爆表 |

**正确做法：**

1. 瓦片图**四边无缝**，不带描边
2. 相邻瓦片**重叠 1~2px**，不留缝
3. 地形交界用**过渡瓦片**（草地→土路有 2~3 种中间态）
4. 接缝处用**装饰物**盖（草丛、碎石、花）

### 4.2 变化（避免一眼看穿重复）

| 项 | 规格 |
|---|---|
| 变体 | 同类 **3~4 种**，随机铺 |
| 低频明暗 | 整片区域有明暗起伏（低频噪声，不是每格一样） |
| 密度 | 边缘可以更密、中心更疏 |

### 4.3 颜色

| 项 | 规格 |
|---|---|
| 饱和度 | 中（**不要荧光绿**） |
| 明度 | 中（不要亮到刺眼） |
| 色相 | 偏暖（黄绿 > 蓝绿） |

**参考**：牧场物语的草地是「黄绿 + 土色斑」，不是纯绿。

### 4.4 规格表

| 项 | 规格 |
|---|---|
| 单元 | 俯视方格瓦片（mir）；一格一块大石板 |
| 尺寸 | 每格 48px（主城石板贴图可用 64px） |
| 种类 | 每主题 4~6 种 + 过渡瓦片 |
| 风格 | 卡通手绘：色块 + 少量纹理 |
| 无缝 | **必须**，四边不露白、不描边 |
| 变体 | 同类 3~4 个 |

**做法**：程序化生成瓦片贴图（Canvas 画），按地形数据铺。**代码生成，不需要美术。**

## 四·五、排序规则（角色站在屋顶上，就是这条没做）

**所有立着的东西按「脚底屏幕 y」排序，不按固定层。**

| 层 | 规则 |
|---|---|
| 地面 | 永远最底 |
| 立物（角色 / 怪 / NPC / 建筑 / 树 / 道具） | 按**脚底 y** 从小到大画，y 大的后画、盖住前面的 |
| 特效 / 飘字 | 立物之上 |
| 名字 / 血条 / UI | 最上 |

**为什么**：固定层序（地面→建筑→角色）会让角色要么永远在建筑上面、要么永远在下面。**只有按脚底 y 排，才能「走到房子后面就被挡住」。**

**注意**：建筑占多格时，排序基准是**占地区域最下面那一行的 y**，不是中心点。

---

## 五、层次（空间感）

| 层 | 做法 |
|---|---|
| 前景 | 略压暗、降饱和 |
| 中景 | 正常亮度（视觉中心） |
| 背景 | 降对比、偏浅偏冷 |

**至少三层明度分开。** 童话风不要重雾，用「远处偏浅」代替。

---

## 六、装饰密度（打散单调）

| 项 | 规格 |
|---|---|
| 地面装饰 | 每屏 ≥ 8~12 个（小花、蘑菇、碎石、木桶、脚印） |
| 边界装饰 | 瓦片交界处必须有东西遮（矮栅栏、灌木、花丛） |
| 密度衰减 | 离中心越远越稀 |
| 风格 | **可爱小物**，不要碎石瓦砾那种破败感 |

---

## 七、资产分类：谁能用代码生成

| 类别 | 做法 | 说明 |
|---|---|---|
| 地面瓦片 | ✅ 代码生成 | Canvas 画 mir 俯视方格 |
| 接触阴影 | ✅ 代码生成 | 椭圆渐变贴片 |
| 小装饰 | ✅ 代码生成 | 简单形状 + 随机散布 |
| 建筑 | AI 出等距立牌 | 45° 等距、屋顶可见、**Q 版矮胖** |
| 角色 / 怪物 / NPC | AI 出等距精灵 | **3 头身**，等距角度 |
| UI 图标 | AI 或代码 | 圆润、明快 |

**禁止**：用球体/方块/圆柱拼角色和怪物。

---

## 八、验收清单（每屏逐条勾）

- [ ] mir 相机固定，所有资产同一投影角度
- [ ] 地面是**卡通俯视方格瓦片**，不是照片平铺、不是粗黑棋盘格
- [ ] 瓦片边界不规则，没有直线切割
- [ ] 角色是 **3 头身**，建筑是 **Q 版比例**，两者不违和
- [ ] 每个立地物体脚下有椭圆接触阴影，方向一致
- [ ] 全部素材同一色板（明亮暖色）、同一光源方向
- [ ] 有前景 / 中景 / 背景的明度层次
- [ ] 地面装饰密度够，不空
- [ ] **整体调性是轻松可爱**，不是暗黑写实
- [ ] 玩法一行没改，测试全过

**十项缺三项以上，打回重做。**

## 九、给 AI 的提示词模板

### 角色 / 怪物（3 头身等距精灵）

```text
isometric 2:1 hand-painted game sprite, 45-degree top-down view, orthographic,
{cute chibi bean warrior, 3-head-tall proportion, head is one third of total height,
round cream-colored body, two big black dot eyes, pink blush, small red cape,
tiny leather vest, short wooden sword},
bright cheerful pastel palette, thick soft dark-brown outline (#3B2F26),
flat cel shading, top-left key light, no cast shadow,
plain solid magenta background (#FF00FF), single character centered,
no text, no UI, no border, 1024x1024
```

**关键四句**：`isometric 2:1`、`45-degree`、`orthographic`、`3-head-tall`。

### 建筑（Q 版等距立牌）

```text
isometric 2:1 hand-painted building, 45-degree view, orthographic,
{cute chubby medieval shop with red-white awning, big rounded tiled roof,
round door, small round windows, flower boxes},
chibi proportions, roof wider than walls, bright cheerful palette,
thick soft dark-brown outline, flat cel shading, top-left key light,
no cast shadow, plain solid magenta background (#FF00FF),
single object centered, 1024x1024
```

**Q 版建筑三要点**：屋顶比墙宽、门洞圆、颜色明快。

### 后处理（每批出完都要跑）

```text
把 assets/iso/raw/ 里的所有图：
1) 抠掉洋红底（容差 18，边缘收 1px）
2) 缩放到目标尺寸（LANCZOS）
3) 映射到统一色板 palette.json（明亮暖色）
4) 统一色温（偏暖）、对比度（中低）、饱和度（中高）
5) 锚点对齐到脚底中心
6) 拼图集 + 写 manifest
不改变构图，只统一色调。每批出 review 预览图。
```

## 十、可选进阶（现在不做）

| 手段 | 效果 | 成本 |
|---|---|---|
| 轻雾 / 远处偏浅 | 纵深 | 低 |
| 柔光 bloom | 童话光感 | 低 |
| 局部光源 | 窗户、火堆发光 | 中 |
| 3D 光照 / PBR | 物理真实 | 高（和童话风不搭，不建议） |

**前两项可以加，后两项不符合童话定位。**
