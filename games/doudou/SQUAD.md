# 守护豆豆 · 小队模式（架子 v0.3）

参考玩法：微信小游戏《小小生存队》。**只借了结构，没有抄内容**（没有碎片、宝箱、广告位）。

入口：`games/doudou/index.html` 右上角「小队模式」；直接打开 `squad.html` 也行。

## 为什么单独一个文件

经典 `game.js` 是自包含 IIFE，硬拆成模块风险大。所以：

- `game.js` / `index.html` 的经典玩法 **一行没改**（只多了个入口链接）
- `squad.js` 独立实现，`squad.html` 用自己的页
- 共用 `style.css` 的舞台缩放和配色变量，`squad.css` 只补两个入口按钮的样式

## 结构

```
准备（时间冻结）→ 拖人进格 / 两个一样的合成 → 开战 →
清场 → 三选一强化 + 解锁格子 → 回准备。15 波，基地血 18。
```

金币有两个来源（原版就是这样，不是打怪掉）：**每秒 +1**，加每清一波的固定奖励（`15 + 波数×3`）。

### 格子：一条会长的线

**最终 7×5 = 35 格，开局只有中间 3×3 = 9 格。** 每清一波从中心向外解锁 2 格。

这条是参考游戏最值钱的设计之一：**战场本身是养成资源**。前期憋（9 格塞不下几个人），
后期舒展（35 格随便摆），成长感不是数字涨，是**地方变大**。

### 占格：格子从「容量」变成「拼图」

| 兵种 | 占格 | 特点 |
|---|---|---|
| 步枪兵 | 1×1 | 便宜、常见、基准 |
| 霰弹兵 | 1×2（竖） | 三弹丸、近距 |
| 狙击手 | 2×1（横） | 超远、穿透 |
| 重炮手 | 2×2 | 高伤、溅射 90px |

每格输出大致拉平（6~9 dps/格），大单位靠射程 / 穿透 / 溅射赚回占地。
**2×2 在开局 3×3 里刚好放得下**——这是个刻意的门槛。

### 养成：等级卡住合成上限

每个兵种有一个**跨局保留**的等级（存 `doudou.squad.lv`，初始 3 级）：

- **合成上限 = 兵种等级**。3 级只能合到 3 星，想合 5 星得先把兵种养到 5 级
- 等级每升 1 级，基础攻击 +12%
- 升级花的是**局内金币**（每局重新赚），等级本身留着
- 上限 10 级；花费 `60 × 当前等级`

这条把「局内合成」和「局外养成」绑在一起了：局内赚的钱既要刷新、又要升级，是个真实的取舍。

| 项 | 值 | 在哪改 |
|---|---|---|
| 格子 | 7×5，格宽 96 | `GRID` / `CELL` |
| 初始解锁 | 9 格（3×3） | `START_CELLS` |
| 每波解锁 | 2 格 | `settleWave` 里的 `unlockNext(2)` |
| 待命区 | 3 格 | `BENCH` |
| 星级 | 1~5，伤害 ×2.2^(星-1) | `TUNE.starGrowth` |
| 波数 | 15 | `TUNE.waves` |
| 人数 | `round(3 + n×1.5)` | `TUNE.countBase/PerWave` |
| 血量 | `12 × 1.52^(n-1)` | `TUNE.hpBase/hpGrowth` |
| 金币 | 每秒 +1，清波 +`15+3n` | `TUNE.coinPerSec` / `waveBonus*` |
| 三选一 | 每波 3 张：某兵种 伤害+25% / 射速+20% / 射程+15% / 弹道+1，或 +30 金币 | `rollUpgrades` |
| 速度 | `52 + n×3` | `TUNE.speedBase/PerWave` |
| 刷新 | 10 金币，12% 出 2 星 | `TUNE.refreshCost` / `refresh` |

全部走 `TUNE`，模拟器能直接覆盖，不用改文件。

## 操作

- **准备阶段**：拖待命区 → 空格子放人；拖格子里的 → 别处换位；拖到**同兵种同星级**的格子 → 合成，星级 +1
- **占格一直看得见**：场上的单位脚下逐格描边，圈出它占的 w×h；待命区的框宽也跟着变——1×1 一格宽，占 2 格以上的（1×2 / 2×1 / 2×2）两格宽，框内不分割，整块就是它的占位
- 拖大单位时有 **w×h 预览框**：绿=能放 / 金=能合 / 红=放不下；拖回待命区时目标框变绿
- **开战**：点右下角；清完自动回准备，并解锁格子
- 战斗中不能拖、不能刷新
- 鼠标和触摸都走 Pointer Events，多指只认第一根
- 右上角「音效」按钮开关声音

## 模拟结论（100 局，seed=1，smart 策略）

```
通关 71%   失败 29%
平均最高星 5.0   平均合成 65.2 次   平均场上 12.3 人
失败分布：第 15 波 ×28，第 12 波 ×1
```

### 跨局养成曲线（60 局连续跑，等级累积）

```
第 1 局   LOSE  最高 3 星
第 10 局  WIN   最高 4 星
第 60 局  WIN   最高 5 星
总通关率 76.7%
```

> 第一局基本过不了（3 级只能合 3 星），养几局之后就稳了。
> 这就是养成该有的形状：难度不是被调低的，是被玩家养低的。

每波从 6 秒爬到 18 秒，一局约 3.5 分钟。

### 一个反直觉的结论

模拟里试过两种 AI 策略，差距是决定性的：

| 策略 | 通关 | 最高星 | 说明 |
|---|---|---|---|
| 只在**满格**时合成 | **1.7%** | 3.0 | 格子一多就永远填不满，于是永远不合成 |
| **有机会就合** | **100%** | 5.0 | 合成是纯正收益，早合早强 |

> 合成在数值上是**纯赚**的（两个 2 星 = 4.4 倍，合成 3 星 = 4.84 倍）。
> 所以它不是「要不要赌」的决策，而是「**能不能凑齐两个一样的**」的运气。
> 真正紧张的不是选不选，是刷不刷得到。

## 已做

- **音效**：WebAudio 程序化生成，不加载文件。射击 / 合成 / 击杀 / 漏怪 / 开战 / 清波 / 胜负
- **星级质变**：3 星多一条弹道、5 星再多一条；子弹随星级变粗，4 星起发白带光晕；4 星以上脚下光环
- **占格系统**：1×1 / 1×2 / 2×1 / 2×2，拖拽预览、合成、渲染都按 w×h 走
- **格子解锁**：3×3 → 7×5，每波 +2
- **数值模拟**：`squad-headless.js` 通过 vm + 假 DOM 加载真实 `squad.js`

## 待办（按收益排）

1. **单位没有生命、不会被打**——原版是僵尸围上来打人，角色有血、会被打死，霰弹枪兵就是肉盾。
   现在敌人只会闷头往下走，所以「生命」「护甲」「治疗」这些属性全没有意义。这是最大的一块缺口
2. **没有分工**——原版有医务兵（治疗）、工程师（给相邻加护甲）、战争顾问（每秒多产银币）、鼓号队（充能加速）。
   这些是「上谁」的决策来源，比单纯叠伤害有意思
3. **失败还是集中最后一波**——第 12 波只漏了 1 局
4. 敌人种类：现在只有一种小怪

## 爽点笔记（给以后改的人看）

**下注成功那一下**，不是「合成」本身。

- 合成是延迟满足：两个 1 星合成 2 星，短期战力从 2 份变 1 份，长期翻倍
- 要成立必须有三样：**快顶不住的危险**、**看得见的质变**、**差一点的紧张**
- 现在三样都在：危险来自第 15 波，质变来自星级视觉，紧张来自「凑不齐对子」
- 还欠的是**前中期的悬念**——模拟里前 13 波几乎不会输
