## 一句话

主城 + 三扇门（各一种怪）+ 战士 + 技能书 + 区间装备 + 三品级怪 + 保底掉落 + 碾压 + 状态 + 两档 AI + 鸡无伤兜底 + **地上捡袋子**。
**闭环**：鸡养新手（到 5 级）→ 稻草人 → 野狗 → 野猪/首领；**杀怪 → 地上出袋子 → 走过去挑捡**。

## 这一轮做了什么（M1.20）

| 类别 | 内容 |
|---|---|
| **掉落落地** | 装备**不再直接进包**：掉在怪死的那一格变成**钱袋**（同格合并）。走上去、或点袋子寻路过去，才捡 |
| **拾取清单** | 捡起来弹清单，列出袋里每件的**品级字母 + 属性 + ilvl + ↑比身上好**，**一件一件决定捡不捡**，也能"全部捡起"；没捡完关掉，袋子**留在地上**下次还能捡 |
| **袋子外观** | 发光色 + 字母 = 袋里**最好的品级**（S 橙 / A 黄 / B 蓝 / C 白），多件标 ×N，遗物袋画成 🎒 |
| **金币药水** | 照旧**即时入账**，不进袋子（不然每只怪都要弹窗） |
| **死亡掉装备** | 50% 概率掉 1 件身上穿的（武器/护甲随机），变成**遗物袋**留在倒下的格子；回那个房间走过去就能捡回来。经验和原来一样扣 5% |
| **品级写出来** | 装备全带 **C/B/A/S 字母徽章 + `字母 名字`**：背包、装备槽、拾取清单、掉落提示、顶部装备栏都有，不再只靠颜色 |
| **品级直接显示** | 品级 C/B/A/S 一捡起来就显示（地上袋子也显示），属性也直接可见——**不藏**。上一版把它做成"鉴定后才揭晓"是理解反了，已撤回 |
| **词缀位占位** | 词缀系统 M2 才做，装备面板统一显示 `词缀 未鉴定`（虚线灰字），**游戏里没有鉴定功能** |
| **怪物染色** | 名字按品级染色（普通灰白 / 精英蓝 / 稀有黄 / 首领橙），精英以上脚下加同色环、小地图点同色，名字加深色底衬防止贴一起看不清 |
| **S 掉率收紧** | 普通 0.1%→**0.02%**、精英 1%→**0.2%**、稀有 10%→**3%**、BOSS 25%→**6%**。实测从**每 100 只 0.27 件**降到**约 0.07 件** |
| **顺手修的 bug** | 浮动值原来被同时加到攻和防上，导致"精铁剑"带一条"防御 0-6"；现在武器只浮攻击、护甲只浮防御 |

## 架构

```
data.js     表与常量（怪物 / 品级+颜色 / 稀有度+字母 / 掉落概率 / 死亡惩罚 / AI / 房间怪池 / 等级差经验）

status.js   状态引擎：施加 / 叠层 / 回合末结算 / 能否行动 ← 加状态只改这里

```

## 本轮关键教训

- **"期待感"来自停顿**：掉落直接进包就没有任何仪式感；落地 + 走过去 + 打开清单，三步就把"这只怪出了什么"变成了一个事件
- **但停顿不能太多**：金币和药水要是也进袋子，每杀一只怪都弹窗，期待感立刻变成烦躁——所以只有装备落地
- **别把"还没有的东西"做成隐藏机制**：词缀系统没做，就用一句话占位（`词缀 未鉴定`），不要顺手把品级和属性也一起藏起来——那样玩家连"该不该捡"都判断不了
- **品级不能只靠颜色**：颜色在老显示器/色弱玩家那里等于没有；字母徽章是兜底，颜色只是加速识别
- **惩罚要看得见**：死亡掉装备如果只是"默默少一件"，玩家只会觉得是 bug；写进结算面板 + 遗物袋留在原地，才是一次完整的教训
