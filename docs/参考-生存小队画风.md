## 〇、一句话

> **2 头身 + 深色描边 + 大色块 + 彩色编队框 + 低饱和背景托高饱和角色。**

## 二、五条画风规则（对着截图拆的）

### 1. 2 头身 + 深色描边 + 大色块

- 头约占**身高一半**，圆头、大眼、短腿，正面或近正面。
- 描边是**深棕 / 深紫**，不是纯黑（纯黑会硬）。
- 身上**几乎没有纹理**，靠剪影认人：枪的形状就是兵种身份。
- 兵种剪影对照：步枪＝直枪管；霰弹＝短粗；狙击＝长管＋镜；炮＝粗筒。

### 2. 背景低饱和，角色高饱和

- 地面是**暖沙 / 土黄**，草边是**低饱和绿**，整体发灰一点点。
- 角色的粉、青、黄是全画面**饱和度最高**的东西。
- 效果：视线自动被角色吸走，不用发光、不用描边加粗也能突出。

### 3. 彩色半透明编队框（它最标志性的一条）

- 每个上阵单位外面一个**半透明彩色方框**，青 / 绿 / 粉 / 紫轮着来。
- 左上角一个**小数字角标**标星级。
- 视觉语义：**格子是容器，框是归属**。玩家看框就知道「这个人归这个格子」。
- 这条比「画得多精细」重要——它是**界面语言**，不是美术装饰。

### 4. 厚糖果按钮 + 拟物面板

- 主按钮（Fight!）是**黄色厚圆角 + 底部硬投影 + 一条顶部高光**，按下去像按实体糖。
- 底部是一整块**深灰蓝金属面板**，不是透明浮层。
- 信息用**胶囊 / 卡片**承载，不用细线分割。

### 5. 45° 斜俯视 + 正面立牌

- 战场是斜 45° 的街道，角色是 2D 立牌**正面朝镜头**，脚下一块椭圆投影。
- 这个视角是它「像街道」的关键——**也是最难抄的一条**（见第四节）。

## 三、纯 Canvas 程序化能还原到什么程度

DDGame 的规矩是「程序化就是成片、不引外部图」（根 `AGENTS.md` 第 4 节），所以不可能真画立绘。用几何拼，能做到：

| 规则 | 纯 Canvas 可行性 | 做法 |
|---|---|---|
| 2 头身 + 描边 + 大色块 | **能，且值得** | 圆头 + 梯形身 + 两截短腿 + 枪形；`stroke` 用深色 3px |
| 低饱和背景 | **能** | 底色 #cbb68f 一类，格子用低对比白线 |
| 彩色编队框 | **能，最划算** | 单位外 `strokeRect` 半透明色 + 左上角数字角标 |
| 糖果按钮 | **能** | 圆角矩形 + 底部偏移深色块当投影 + 顶部 1px 亮线 |
| 45° 透视 | **不建议** | 牵动命中判定 / 拖拽坐标 / headless 全链路 |

**结论**：前四条拼完，观感能到「像」的七成左右；第五条单独一个工程。

## 四、不要照搬的

1. **45° 透视**。它是横屏街道的产物。DDGame 的竖屏游戏（720×1600）直接照搬会挤，且要动判定链路。
2. **横屏构图**。它的战场是横的、角色在中间一横排。竖屏照搬等于把战场砍一半。
3. **广告位**。它的 Reroll 按钮带油管图标、`Slots x2` 是看广告换的。这套是变现层，不是美术，别学。
4. **它的数值/关卡结构**。那是玩法，本文只谈画面。

## 五、和 DDGame 已有规格的关系（重要）

`docs/渲染规格.md` 已经定了：

- 角色 **2 头身豆豆**（头约占身高 1/2），圆润、表情清楚；
- 线：**柔和的深色描边，不要纯黑硬边**；
- 色板：**明亮暖色为主**（奶油、暖黄、草绿、砖红），不要暗黑。

**这跟《Survival Shelter》是同一套语言。** 所以主人喜欢它不是「跟风」，是「一直想要的那套」——跟 `docs/角色设定.md` 的豆豆是自洽的。

差别只有一处：DDGame 现在是**暗色底 + 亮角色**（`squad` 用深蓝黑背景）；它反过来是**暖色底 + 亮角色**。要靠近它的味道，改的是**底**，不是角色。

## 六、如果以后要动手，顺序

按性价比排（**现在不做，只记着**）：

1. 单位立牌（头 + 身 + 短腿 + 枪）——观感提升最大；
2. 彩色编队框 + 星级角标——标志性最强、改动最小；
3. 地面换暖沙色、加草边；
4. 按钮改糖果按钮、面板改浅灰蓝；
5. 45° 透视——最后，或者永远不做。

前三件都不碰玩法逻辑，可以单独验证「像不像」再决定往下走。
