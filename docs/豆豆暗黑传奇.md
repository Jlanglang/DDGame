# 豆豆暗黑传奇 — 设计笔记

> 状态：**立项笔记，未开工**。这份文档只记结论和决策依据，不包含实现。
> 定位：传奇战士与道士 × 暗黑刷装地牢 × 纯文字/色块 × 单机页游。
> 目标 id（暂定）：`games/darklegend/`
> 配套：规则清单与任务分解见 [`豆豆暗黑传奇-规则与任务.md`](豆豆暗黑传奇-规则与任务.md)（每条规则有编号、数值、验收）

## 0. 一句话

**传奇的底材，战士与道士，暗黑的词缀与随机地牢，去掉美术，做成一个打开就能刷的单机页游。**

> v4 决策：只保留**战士 + 道士**，**不设流派**。首版是"两个简单职业"，不做天赋树。
> - 战士：硬扛刷怪，靠血量和防御正面推进
> - 道士：宝宝扛 + 隐身躲 + 毒磨血，靠技术越级打怪
> - 每职业 6 个技能，6 格快捷键刚好放满
> 删法师的理由：本版没有走位群怪，AOE 没目标；没有远程，距离没意义。

单机的核心矛盾是"没有炫耀对象"，所以本作把炫耀从"给别人看"改成"给未来的自己看"：
冒险日志、build 名片、种子分享、最速/通关记录。

## 1. 核心决策速查

| 决策 | 结论 | 理由 |
|---|---|---|
| 战斗模式 | **半自动 + 可暂停 + 可倍速** | 保留"不做决策就少一个更优解"的即时感，又不逼玩家一直盯 |
| 回合长度 | 杂兵 1–3s，普通 6–10s，精英 15–25s，Boss 60–120s | 纯文字没有画面填充，战斗必须压缩；"慢"只留给值得慢的 |
| 世界结构 | **6 张野外图 × 10 级**，每图一个洞穴，传送 + 路口互通 | 传奇是连通的野外，不是暗黑那种往下钻的层；层数语义不对 |
| 空间维度 | **格子化**，距离/仇恨/射程显式化 | 道士要卡位、要拉仇恨，格子是唯一能文字化的空间 |
| 多打一下 | **连击词条**，不做攻速/移速 | 百分比攻速在文字界面算不清，还连锁影响行动顺序；固定出手顺序最省心 |
| 职业分工 | 战士硬扛刷怪 / 道士越级打怪 | 两种焦虑，两种玩法，不是两个换皮 |
| build 分叉 | **首版不设流派**，战士 5 技能 / 道士 6 技能，靠装备自然分叉 | 先做"简单两职业"，流派留给以后 |
| 技能获取 | 基础技能升级即学；**强力技能靠技能书掉落** | 给"打怪"一个装备之外的长期目标 |
| 世界时钟 | 在线时真实流逝；战斗用回合，**怪物刷新/世界事件独立运行** | 世界不能等你按下回合 |
| 装备系统 | 底材 × 稀有度 × 词缀 × roll，**预算制** | 词缀多不等于强，只等于杂 |
| 数值规模 | 底材小斜率、等级 +1.5/级；成长靠**词缀% + roll** | 底材定下限、词缀定上限，数字不爆炸 |
| 防御机制 | 传奇式：攻/防取**区间**、硬减、幸运取上限、准确/敏捷判命中 | 百分比减伤在低数值下会卡成"打 1 血"，区间硬减更像传奇 |
| 等级节奏 | 1–30 打怪；**30+ 零经验，只吃经验珠**；每日限时挂机产珠 | 升级不该占大头，时间留给找 BOSS、打宝 |
| 材料经济 | 矿石/肉等材料由**区域怪物掉落**，不做采集动作 | 少一个系统，经济照样转 |
| 经济循环 | 金币买药水；**矿石换祝福油**（武器 +幸运，提高取上限概率）；**无强化、无修理** | 传奇靠祝福油养武器，比强化更对味 |
| 掉落 | **概率公平、产出分层** | 单件概率垃圾怪也能出极品（爽点），但 Boss 掉落次数和 ilvl 更高（策略） |
| 平衡目标 | 不是"绝对平衡"，是**"没有退化解"** | 单机唯一解只是"简单模式"，不是天灾 |
| 文字表现 | **排版即光柱** + 音效 + 延迟揭示 | 复刻"一眼看出好坏"的 0.1 秒，不复刻 3D 粒子 |
| 信息呈现 | 状态用符号常驻，事件用一句话播报，决策只给 3 个选项 | 看不过来不是信息多，是没排优先级 |
| 单机氛围 | 伪世界频道、传闻、世界事件、NPC 作息、地图痕迹 | 用文字伪造"他人在场"，成本极低 |

## 3. 战斗与节奏

### 3.1 回合长度谱系

即时战斗本质是"1 秒一回合的回合制"。文字版可以选择停在哪一格：

| 回合长度 | 气质 | 本作取舍 |
|---|---|---|
| 0.3–1s | 动作 | 不做（文字没有表现力） |
| **2–5s** | **战术** | **杂兵/普通怪** |
| **8–20s** | **策略** | **精英/Boss** |
| 不限时 | 解谜 | 暂停推演时 |

### 3.2 爽感公式

```
爽感 ≈ 决策密度 × 单个决策价值 × 反馈强度
```

即时版是"很多小爽"，文字版做"少量大爽"。文字版要守住的不是"实时"，是**"时间在收税"**：
不做决策，就少一个更优解。

### 3.3 三层结构

```
底层：自动战斗（0.5s tick，AI 按优先级出招）
干预：玩家随时插入（技能/喝药/走位/召唤）
速度：1x / 2x / 4x，可暂停
反馈：日志 + 数字跳动 + 音效 + 色块
```

- 手动不是门槛，是**效率**：手动更省药、更快；自动也能过，只是慢。
- 关键：**没人被门槛挡住，操作变成奖励。**

### 3.4 反应时限与走位

- **反应时限**：每回合给 1–3 秒（可设置），超时自动普攻。保留"时间在收税"，但**待评估**——3 秒对手机可能太紧，1 秒对策略玩家太赶。
- **走位**：移动 1 格消耗 1 回合，走位当回合 **80% 概率躲避攻击**，模拟即时走位。
- **防御动作取消**：没有"防御"这张安全牌，犹豫的代价就是挨打。

### 3.5 死亡与回城

- **死亡**：随机掉 1 件装备 + 当前等级经验 5%；经验归 0 不掉级；掉的装备有概率被击杀者捡走，**回去杀了它拿回来**。
- **回城**：不是"逃跑"，是直接回城，记录点位和 BOSS 信息，可以传回原位。
- **没带回城卷被围 = 必死**——这不是 bug，是设计：让"带卷"变成出门前的决策。

### 3.6 节奏 × 掉落必须耦合

| | 慢战斗 | 快战斗 |
|---|---|---|
| 少掉落 | 苦修（每件珍贵） | 挫败（打半天没东西） |
| 多掉落 | 疲劳（一堆垃圾） | 割草爽 |

本作选：**快杂兵 + 慢精英/Boss**；"慢"的地方给确定性（必掉），"快"的地方给数量。

## 4. 职业分工：战士硬扛，道士越级

| | 战士 | 道士 |
|---|---|---|
| 战斗方式 | 贴身硬扛，靠血量和防御 | 宝宝扛、隐身躲、毒磨血 |
| 强项 | 正面推进、清怪 | **越级打怪**、消耗战 |
| 弱项 | 越级打不动 | 正面硬扛会死 |
| 玩家在算什么 | 血够不够、格挡时机 | 宝宝还能扛几回合、毒叠了几层 |

### 4.1 每个职业几个技能，强力技能靠技能书

**首版不做天赋树、不做流派。** 基础技能升级即学，强力技能要靠打怪掉技能书。

| 职业 | 基础技能 | 技能书技能 |
|---|---|---|
| 战士 | 普通攻击、半月弯刀 | 烈火剑法、野蛮冲撞、狮子吼 |
| 道士 | 灵魂火符、治愈术、施毒术、召唤骷髅 | 隐身术、召唤高级宝宝 |

**为什么先不做流派：** 流派是"给熟手加深度的第二层"，首版要先验证"两个职业本身好不好玩"。流派可以后加，加早了只会让平衡翻倍。

### 4.2 道士越级流（必须保留的爽点）

核心是"用机制绕过数值"：

- **隐身** = 仇恨清零（不是"怪看不见你"，是"仇恨列表里没有你"）
- **火符 = 高仇恨**（×3）：一放，怪就转头打道士——所以"宝宝扛着、自己无限火符"不成立，除非道士扛得住。这条比任何 CD 都更能限制道士的输出
- **毒** = 低仇恨（×0.2）的固定伤害，才是"宝宝扛、道士磨"的常规输出
- **毒** = 无视防御的**固定伤害**（只看道术，与目标血量无关；打 5000 血 BOSS 和 500 血小怪，每回合掉血一样）
- **宝宝** = 独立单位，有 HP / 攻击 / 仇恨，会死，需要重召

文字版把越级变成**一道有风险的数学题**：

```
【第 12 回合】你处于隐身（剩余 3 回合）
祖玛教主  3200/5000   中毒 1 层 · 每回合 -45
你的骷髅   420/900     正在承受攻击
它下回合会放 AOE，骷髅大概率倒下
→ 补毒 / 重召骷髅 / 现身放符
```

**实时版是"手忙脚乱的爽"，文字版是"算无遗策的爽"。**

关键配置：毒必须 `ignoreDefense: true`，**固定伤害只看道术**，否则越级打不动 BOSS。

### 4.3 设计铁律

**任何 build 最多同时占"高输出 / 高生存 / 低操作"两样。**

- 战士：高输出 + 高生存，但操作繁琐（贴脸）
- 道士：高生存 + 低操作，但输出慢（靠磨）
- 想三样都要 → 必须用装备补 → 词缀预算正好让他失去前两样

### 4.4 经验与等级差

- **升级经验**：`expNext(L) = 100 × 1.18^(L-1)`
- **怪物经验**：`monsterExp(L) = 10 × 1.12^(L-1)`（精英 ×3、Boss ×15）
- **每级杀怪**：1 级 10 只 → 30 级 45 只（累计约 350 只）；**30 级起击杀零经验**，改吃经验珠，每级 5 颗、约 100 只同级怪
- **时间分配**：1–30 级约 2 小时；31–60 级约 12–15 小时（含打宝、找 BOSS、材料）；全流程 15–17 小时
- **难度旋钮**：升级倍率 1.18 → 1.20 只影响前 30 级（60 级前已改用珠子）

| 等级差（怪 − 人） | 经验系数 |
|---|---|
| ≥ +10 | ×2.0（越级奖励，封顶） |
| +5 | ×1.5 |
| 0 | ×1.0 |
| −5 | ×0.5 |
| −9 | ×0.1 |
| ≤ −10 | ×0（不给） |

- **防刷低级图**：高 10 级以上零经验
- **奖励越级**：道士越 10 级打怪，双倍经验——越级不只是能打，是划算
- **平滑过渡**：−1 到 −9 逐级衰减，不会"差 1 级就归零"

## 5. 词缀系统

### 5.1 四个维度

一件装备 = **底材 × 稀有度 × 词缀 × roll**。

- 底材：决定基础属性和可带词缀数（传奇经典名：屠龙、裁决、逍遥扇、无极棍、天尊道袍……）
- 稀有度：白 0 / 蓝 1–2 / 黄 3–4 / 橙 4–5（首版无特技）
- 词缀：按**槽位分池**（武器/防具/首饰），再分通用 + 职业专属（战士/道士）
- roll：同词缀在档位内随机

### 5.2 防"唯一解"的五件工具

| 工具 | 作用 |
|---|---|
| **代价词缀** | 强力必带负面：+25% 连击率 / −20% 准确 |
| **预算制** | 每件装备固定词缀预算，4 条小词缀 ≈ 2 条大词缀 |
| **互斥组** | 攻击组（连击/攻击上限/破甲）三选一；防御组（格挡/敏捷/反伤）三选一 |
| **上限** | 幸运封顶 9；连击率硬上限 50% |
| **乘法协同** | 幸运 × 攻击上限、连击 × 吸血、反伤 × 格挡、毒伤 × 毒持续、破甲 × 攻击上限 |

### 5.3 词缀 tier

同一条词缀做 6 档，ilvl 决定能出到第几档。这样"刷到 60 级图"是为了**词缀档位解锁**，不只是经验。

### 5.4 检查清单（每条词缀过五问）

1. 它有代价吗？
2. 它和谁协同？
3. 它和谁互斥？
4. 堆到极限会怎样？
5. 什么情境下它最强？

五问全过的词缀，每职业 20 条就够撑 50 小时。

## 6. 掉落系统

### 6.1 概率公平，产出分层

| 怪物 | 掉落次数 | ilvl 加成 | 单件极品概率 |
|---|---|---|---|
| 普通 | 0–2 | +0 | 一样 |
| 精英 | 2–4 | +5 | 一样 |
| Boss | 5–8 | +10 | 一样 |

- 单件概率公平 → "垃圾怪出极品"的爽点成立
- 次数 + ilvl 分层 → 最优策略自然落在"打能打的最高图"，而不是刷最弱的图
- **双职业需要智能偏向**：70% 掉当前职业可用，30% 全随机

### 6.2 保底三件套

| 工具 | 做法 |
|---|---|
| **PRD（伪随机）** | 第 n 次未出货概率 = base + n × step，出了重置 |
| **保底计数** | 黄装 50 次必出、橙装 500 次必出，存进存档 |
| **三层节奏** | 过渡装 3–5 分钟（蓝装）/ 可用黄装约 1 小时 / 毕业橙装 8–12 小时 |

### 6.3 调参看 P99，不看均值

| 指标 | 目标 |
|---|---|
| P50 | 约 1 小时出可用黄装 |
| P90 | 2 小时内 |
| **P99** | **不超过 3 小时** |

**玩家骂的不是"爆率低"，是"我怎么这么非"**。压方差比压均值重要。

### 6.4 反直觉

**爆率别调太低。** 单机没有社交炫耀，稀有度低的爽点兑现不了。推荐毕业装 8–12 小时一件，配合"提升装 30 分钟一件"，让玩家一直处于"差一件"的状态（目标梯度效应）。

### 6.5 配置示意

```json
{
  "monster": {
    "normal": { "rolls": [0, 2], "ilvlBonus": 0 },
    "elite":  { "rolls": [2, 4], "ilvlBonus": 5 },
    "boss":   { "rolls": [5, 8], "ilvlBonus": 10 }
  },
  "rarity": { "white": 60, "blue": 30, "yellow": 9, "orange": 1 },
  "prd": {
    "yellow": { "base": 0.09, "step": 0.01 },
    "orange": { "base": 0.01, "step": 0.002 }
  },
  "pity": { "yellow": 50, "orange": 500 }
}
```

## 7. 反"唯一解死循环"

**唯一解不是 bug，是玩家优化的终点。** 用"削弱"对抗"优化"，是拿线性人力追指数搜索空间。

### 7.1 降维（工程）

词缀按互斥组压缩有效维度：20+20 条词缀 → 12 个互斥组 → 组合数从百万降到几千，**几千是跑得完的量**。

### 7.2 模拟器（工程）

无渲染战斗模拟器，穷举所有有效组合 × 两职业 × 20 套怪，跑 10 万场，看分布。
**Top 1% 异常组合 = 未来玩家会发现的唯一解**，在玩家之前先看到。

**铁律：削数值，不删机制。** 前者是调参，后者是背叛。

### 7.3 环境轮转（设计）

不追着削，用"换战场"让位：

| 图段 | 主题 | 上个唯一解会怎样 |
|---|---|---|
| 图 1–2 | 荒坟（高物抗） | 战士输出变弱，道士毒伤变强 |
| 图 3 | 毒沼（群怪） | 单体技变弱，宝宝变强 |
| 图 4 | 祭坛（高反伤） | 高频输出变弱，连击/毒伤变强 |
| 图 5 | 雪山（减速） | 连击流变弱，攻击上限流变强 |
| 图 6 | 遗迹（综合） | 偏科 build 都吃瘪 |

**不是削弱，是换战场。** 唯一解有保质期，每张图换一次（约 3 小时）。

### 7.4 三选二（心理）

任何 build 最多占"高输出 / 高生存 / 低操作"两样。想三样都要，就得用装备补，而补第三样所花的词缀预算，正好让他失去前两样的优势。

### 7.5 单机的宽容

验收标准只有两条：
1. 没有"不付代价就通吃"的组合（真 bug）
2. 每个看起来合理的 build 都能通关（及格线）

**唯一解在单机里只是"简单模式"，不是天灾。**

## 8. 传奇的时间锁，单机不能照搬

| 传奇机制 | 网游功能 | 单机结果 |
|---|---|---|
| Boss 刷新 4–6 小时 | 制造抢 Boss 竞争 | 只剩干等 |
| 副本次数限制 | 控产出、稳物价 | 拖时间 |
| 固定刷新时间 | 培养上线习惯 | 玩家随时能玩，不需要打卡 |

**核心可迁移的不是"锁时间"，是"稀缺性分配"：**

| | 稀缺性放在哪 |
|---|---|
| 暗黑 | 概率（1% 爆率） |
| 传奇 | 次数（每天 2 次） |
| **单机** | **成本（越刷越贵）** |

单机替代品：

- **门票制**：打怪掉门票，攒够进本（限制节奏，主动权在玩家）
- **成本递增**：第 N 次进本门票 ×1.15^N（自然收敛）
- **收益递减**：同副本刷太多次，掉率缓降，有下限
- **偶遇 Boss**：地图随机刷世界 Boss，有时间窗口（惊喜，不是门槛）

**核心：让玩家自己决定刷多久，但让"刷太久"变得不划算。**

## 9. 文字表现

### 9.1 排版就是文字版的光柱

| 视觉手段 | 文字版对应 |
|---|---|
| 橙色光柱 | 物品名金色 + 加粗 + 底纹色块 |
| 掉落闪光 | 名字短暂放大/闪烁 |
| 光柱高度 | 词缀条数（橙装 5 条，白装 0 条） |
| 传奇音效 | 单独的"叮——" |
| 屏幕震动 | 边框泛光 / 短促抖动 |
| 物品图标 | 描述文字的长度和质感 |

### 9.2 三个零成本补偿

1. **音效分级**：白"嗒"、蓝"叮"、橙独有"嗡——"（性价比最高）
2. **延迟揭示**：捡起 → 停顿 0.5s → 逐字打印名字
3. **开箱式展开**：词缀逐条跳出，最后一行是特效

### 9.3 承认天花板

- 视觉版：即时、生理、可重复，但 100 小时后脱敏
- 文字版：延迟、想象、可沉淀，靠描述质量维持

**文字版上限低，下限高。**"光柱只能亮一次，一段好描述能被记十年。"

## 10. 信息架构（防过载）

**看不过来不是因为信息多，是因为所有信息一样重要。**

### 10.1 三招

| 招 | 做法 |
|---|---|
| **符号化** | 状态用符号+数字（`☠5·3`、`👻2`），事件才用句子 |
| **分层** | 常显血/位置；剩余 ≤2 回合才亮提示；详情折叠 |
| **分区** | 左自己、右敌人、下决策，用空间记忆代替阅读 |

### 10.2 布局示意

```
┌─ 你 ──────────────┐   ┌─ 祖玛教主 ─────────┐
│ HP ████████░░ 820  │   │ HP ██████░░░░ 3200 │
│ MP ██████░░░░ 210  │   │ ☠5·2   ⚠→宝宝      │
│ 👻2   🦴骷髅 420   │   │ 距离 2 格           │
└───────────────────┘   └────────────────────┘
──────────────────────────────────────────────
【第12回合】教主转向骷髅，你还在隐身
→ [补毒]  [重召]  [现身放符]
```

### 10.3 日志只记变化

**日志是"新闻"，不是"流水账"。** 不写"毒造成 180"×3，只写"毒即将消失（剩 1 回合）"。

## 11. 单机的"味"：伪造他人在场

主人怀念的不是社交，是**"世界的背景音"**。纯文字擅长伪造这个——只需要叙述，不需要渲染。

| 手段 | 做法 | 成本 |
|---|---|---|
| 伪世界频道 | 滚动 NPC/传闻消息 | 1 天 |
| 传闻系统 | NPC 谈论随机生成的"别的冒险者" | 1 天 |
| 世界事件 | 定期公告"石墓出现异动" | 1 天 |
| NPC 作息 | 商人白天在、晚上关门 | 1 天 |
| 地图痕迹 | 尸体、篝火、潦草留言 | 1 天 |
| 排行榜残影 | "本图最快纪录：某冒险者 3:12"（本地假数据） | 0.5 天 |

**六样 5 天，全是一张文字表，能把"死寂的世界"变成"有回音的世界"。**

### 11.1 内化炫耀

| 手段 | 做法 |
|---|---|
| **冒险日志** | 通关生成"你的传奇"：第几天、遇到谁、掉了什么、当时 build——可截图分享 |
| **种子分享** | 地牢种子码，别人输入同一地牢 |
| **build 名片** | 装备/词缀/技能/地图进度一页卡 |

### 11.2 氛围来自"低效率"

故意保留"没用但有趣"的东西：能发呆的地方、能闲聊的 NPC、能看很久的文字描述。**效率是玩法，低效率是氛围。**

## 12. 换装：文字版的劣势与解法

图标版换装是"眼睛 + 手"，文字版是"阅读 + 记忆"，硬碰硬必输。**别复刻拖拽，做暗黑做不到的"计算"：**

| 功能 | 说明 | 成本 |
|---|---|---|
| 并排对比表 | 当前 vs 候选，增减 ↑↓ 标红绿 | 1 天 |
| 一键最优 | 自动穿当前 build 最优组合 | 0.5 天 |
| 缺陷高亮 | "你的幸运只有 2，低于推荐值" | 1 天 |
| build 模板 | 存 3 套，一键切换 | 1 天 |
| 词缀筛选 | 背包按属性筛 | 0.5 天 |
| 批量分解 | 按稀有度/ilvl 一键清掉 | 0.5 天 |

**系统给答案，玩家做决定。** 别做成"一键最优就完事"，否则 build 乐趣也没了。

## 16. 一页总结

> **传奇的底材，战士与道士，暗黑的词缀与地牢，纯文字色块，单机刷装。**
>
> 战斗：半自动 + 可暂停，快杂兵慢 Boss，时间在收税。
> 职业：战士硬扛刷怪，道士靠技术越级——两职业两种玩法，首版不设流派，先把"简单"做好。
> 词缀：预算制 + 代价 + 互斥 + 软上限 + 乘法协同。
> 掉落：概率公平、产出分层、PRD 压方差、看 P99 不看均值。
> 平衡：降维 + 模拟器 + 环境轮转，削数值不删机制。
> 表现：排版即光柱，音效补爽感，文字换故事。
> 单机：把炫耀从"别人"换成"未来的自己"，用文字伪造世界的背景音。
