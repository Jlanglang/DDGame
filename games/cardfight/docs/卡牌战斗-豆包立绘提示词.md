# 卡牌战斗 · 豆包立绘提示词

> 用途：生成横版 3v3 战斗用的侧向立绘。
> 建议先做 6 张静态立绘，不要一上来让豆包做序列帧；攻击动画先用代码前冲 + 受击 + 飘字，等静态图稳定后再补帧。
>
> **实测提醒**：如果提示词里出现「豆包」「卡牌」，豆包很容易画成「包子角色 + 卡牌封面」。下面这版已经把这两个词拿掉，并加了负面词；仍然跑偏的话，换即梦 / Seedream，或先只生成「白底贴纸」再抠图。

## 豆包防跑偏版（优先用这段）

```text
画一张游戏角色立绘，不是卡牌，不要卡牌边框、不要 UI、不要多格拼图。

画面里只有一个角色：{把下面某个角色的描述填在这里}。

风格：4头身Q版比例，日系赛璐璐 + 轻微厚涂，干净线稿，暖色左上主光、冷色右下轮廓光。

构图：全身完整，头顶到鞋底留 5% 边距，居中，不裁切；纯白背景 #FFFFFF；不要地面、不要投影、不要文字、不要水印。

朝向：身体和脸都朝画面右侧（3/4 侧身），不要看镜头；战斗待机姿势，双脚分开，重心稳定。

输出：单张，3:4，1024×1536 或 864×1152。如果支持透明背景就透明，不支持就纯白。

禁止：包子，豆包，食物，吉祥物，卡牌，卡框，边框，多格，拼图，贴纸排版，正面站立，看镜头，对称站姿，多手多脚，武器穿模，复杂背景，地面阴影，文字，水印，裁切，低质量，模糊，写实照片，3D渲染。
```

敌方怪物把「朝画面右侧」改成「朝画面左侧」。

## 豆包操作建议

1. 先上传参考图，再发提示词；没有参考图就先发通用段。
2. 比例选 **3:4**，分辨率 1024×1536 或 864×1152。
3. 每个角色生成 4 张，挑：
   - 全身完整、头顶和鞋底都在
   - 脚底没有灰色阴影（有也没关系，我这边会抠掉）
   - 朝向对、脸没有完全正对镜头
4. 如果豆包只能出 JPG/纯白底，直接保存 PNG/JPG 给我，我来抠底。
5. 命名建议：
   - `hero-aurora-right.png`
   - `hero-dajian-right.png`
   - `hero-yueguang-right.png`
   - `monster-golem-left.png`
   - `monster-slime-left.png`
   - `monster-bat-left.png`

放到 `games/cardfight/cutouts/` 即可；位置、血条、怒气交互都不用改。

## 如果豆包也能做动画

先只做 **攻击动作的 3 个关键姿势**（蓄力 / 挥出 / 收招），不要做整段序列帧：

```text
同一角色，攻击动作关键帧，横向排列 3 帧：蓄力、挥出、收招。人物大小、位置、服装、配色保持完全一致，朝右 3/4，纯白背景，无阴影、无文字。每帧都是完整全身。
```

拿回来我按 3 帧做代码补间；AI 直接做 8 帧序列帧通常服装和比例会漂。

## 注意

- 先统一 **4头身 Q 版**；如果要做 6 头身，六张必须一起改，不能混。
- 立绘不要带武器特效/剑气，特效我用代码叠；图里只要人物和武器本体。
- `faces/` 是详情页背景，不要拿它当战斗立绘；战斗立绘只从 `4头身/` 和这套新图出。
