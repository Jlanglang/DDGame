# 守护豆豆 · 主线立牌方案（2026-11-20 初稿）

> 主人定的方向：**主题还是「守护豆豆」，变成 AI 娘作战守豆**。
> 两个模式各管一件事——守桥保持竖屏骨架、只换背面立牌；小队转横屏、把正面立牌展示出来。
> **本文是方案，未写代码、未出图。**

---

## 〇、一句话

> **守桥不换骨架，只换一张背面立牌；小队转横屏，正面立牌才有地方站。**

这样「背面」只出现一次（守桥），「正面」有整整一张横屏可以展示（小队），正好对齐《Survival Shelter》的横屏街道。

---

## 一、两个模式的分工

| | 守桥模式（`game.js`） | 小队模式（`squad.js`） |
|---|---|---|
| 画面 | 竖屏 720×1600 | **改横屏 1280×720** |
| 角色立牌 | **背面 3/4**（自上而下看桥） | **正面 / 3-4 侧**（朝敌人方向） |
| 玩法 | 不动（左右拖 + 自动射击 + 吃卡） | 不动（占格 + 合成 + 三选一） |
| 出图量 | **1 张**（鲸鱼娘背面） | **8 张**（每个角色 1 张） |
| 改动量 | 只动渲染层 | 布局 + 出怪方向 + 单位渲染 |
| 对齐原游戏 | 不对齐，保持自有骨架 | **对齐**（横屏街道 + 彩色编队框） |

## 二、守桥模式：只换皮

**现状**：玩家是火柴人（`game.js:1363` `stick()`，粉发 + MP5），`drawPlayer` 在 `game.js:1476`。

**改法**：

1. 火柴人换成**鲸鱼娘背面立牌**（`drawImage`），贴到 `p.x, p.y`。
2. 程序化演出（立牌是静态图，动感全靠代码）：
   - 待机：轻微上下呼吸（±2px，2s 周期）；
   - 左右拖：立牌整体倾斜 ±3°；
   - 开火：枪口火花（已有，`game.js:1492`）+ 立牌后坐 1~2px；
   - 受击：无（玩家不掉血，桥头掉血）。
3. 枪口坐标：立牌里要约定「枪口在画布上的相对位置」，`stick()` 返回的 `muzzle` 现在是算出来的（`game.js:1391`），换图后改成读约定比例。
4. **不动**：`BAL`、波次、吃卡、输入、判定。

**出图**：1 张，鲸鱼娘背面 3/4 视角，竖构图（适配 720×1600 舞台里的角色尺寸）。

## 三、小队模式：转横屏 + 立牌

**现状**：`squad.js:17-18` `W=720 H=1600`；`GRID` 7×5×96 居中（`squad.js:26-30`）；待命区在底部 `y=1220`（`squad.js:40-43`）；敌人从顶部出生（`squad.js:50` `SPAWN_Y=250`），往下走到底线扣血（`squad.js:51` `BASE_Y`，`squad.js:862` `e.y += e.speed*dt`）。

**改法**：

1. **舞台**：`W=1280, H=720`；`squad.css` 加横屏舞台覆盖（现在共用 `style.css` 的竖屏 `#stage`）。
2. **布局**：左战场 672×480（7×5×96 不变），**待命区压在底部横排**，按钮、金币、血条占底部右侧（怪物从右边来，底部留给待命区不挡视线）。
3. **出怪方向**：纵向 → 横向
   - `SPAWN_Y` → 右侧出生点；`BASE_Y` → 左侧基地线；
   - `e.y += speed*dt` → `e.x -= speed*dt`；
   - 子弹朝右打（枪口朝右）。
4. **单位渲染**：圆 + 枪管 → **立牌贴图**（512×512 透明 PNG），脚底投影 + 呼吸。
5. **星级语言**：数字角标 → **彩色半透明编队框 + 左上角星级**（对齐《Survival Shelter》）。
6. **不动**：占格（1×1/1×2/2×1/2×2）、合成、波次、三选一、金币。

**涉及位置**：`squad.js:862`（移动轴）、`467-471`（出生）、`858-880`（底线扣血）、`1275`（单位渲染）、`1168`（网格框）、`1461`（HUD）、`squad.css`。

## 五、出图清单与规范

| 项 | 张数 | 尺寸 | 用途 |
|---|---|---|---|
| 鲸鱼娘背面立牌 | 1 | 竖构图（约 512×768） | 守桥模式 |
| 角色正面立牌 | 8 | 512×512 透明 | 小队模式 |
| 背景（街道 / 桥面） | 2 | 1280×720 | 两个模式各一 |
| 敌人 Q 版 | 2 | 约 256×256 | 小兵 + BOSS |

**合计约 13 张**。立牌是静态的，动作全程序化——这是「图不多」的根本原因。

**立牌规范**（防止即梦出图风格飘）：

- 透明底 PNG，512×512（守桥背面另算竖构图）；
- **2~3 头身**，Q 版，与《Survival Shelter》同一比例语言；
- 深色描边 4~6px（深棕/深紫，不纯黑）；
- 统一光源：左上；
- 小队立牌朝右（面对敌人），守桥立牌朝上（背对镜头）；
- **鲸鱼娘配色：冰蓝系**（头发/尾巴/主色），和暗色桥面形成冷暖对比（2026-11-20 主人定）；
- 无背景、无文字、无阴影（阴影程序画）；
- **先出鲸鱼娘 1 张定标准，锁定提示词与 seed，再批量**。

## 六、建议顺序（先验证最不划算的一步）

1. 出鲸鱼娘背面 1 张 → 贴进守桥 → 看暗色桥面上协调不协调（这是唯一「只出一张图就能验证」的环节）。
2. 小队横屏骨架（先不放图，用程序化占位）→ 验证拖拽、占格、出怪方向都对。
3. 出鲸鱼娘正面 1 张 → 贴进小队 → 验证 96px 格子里的辨识度。
4. 定稿后再批量出剩下 7 张。
