## 一句话

**把现在所有 emoji 和色块换成 PNG**。重点不是"多画几张瓦片"，而是让画面**像一张真实地图**：
地面有连续的材质过渡（草→土路→石地）、有水系和悬崖、有树石挡住角色，而不是 32px 方块拼出来的棋盘。

29 张图集、**943 格**。地形 32px 像素，角色 / 怪物 / 物品 / UI 高清卡通描边（豆豆系列），主角是**豆豆**。
分两步走：**先只做视觉（碰撞不动），跑通后再让水/悬崖/大树真的挡路**（见 §3.1d）。

**A 阶段只换"画出来的那层皮"**：碰撞、寻路、刷怪、战斗、存档、`SAVE_KEY` 一行都不动。
B 阶段才让深水 / 悬崖 / 大树真的挡路，单独一轮、单独验收。

### 1.2 通用硬规格

| 项 | 规格 |
|---|---|
| 格式 | PNG，RGBA 8-bit，非交错，sRGB |
| 透明 | **地面 base：满格不透明**；过渡边 / 装饰 / 墙 / 水：**透明底**（要能叠在 base 上） |
| 字 | **任何图里都不许写字**（名字、Lv、C/B/A/S、价格全是代码画的） |
| 阴影 | 不许把地面投影烘进图里，统一由引擎画椭圆（§5.6） |
| 描边 | 高清资产一律深色描边：96 格 → 4px；128 格 → 5px；192 格 → 6px；64 格 → 3px |
| 内边距 | 图标类内容占格子的 88%（64 格留 4px 边），不许贴边 |
| 网格 | 所有图集**无间距、无外边距、格子严格对齐**，第 0 格左上角就是 (0,0) |
| 索引 | `帧序号 i` → `col = i % 列数`，`row = Math.floor(i / 列数)`（行优先） |
| 体积 | 全套 ≤ **100 MB**。单张不卡 400 KB。尺寸以 §1.3 为准，不为了把文件做大而放大格子。存 RGBA PNG，可以压缩，**不用 PNG-8** 把描边和过渡压脏 |
| 命名 | 小写 + 短横线；**文件名和本文档一字不差** |

## 三、逐张明细

### 3.1 地形：三层图集（"像真实地图"的地基）

**先记住为什么不能只画 4 个地面变体**：逐格随机换 = 电视雪花；全用同一张 = 棋盘。
真实地图靠四件事，缺一不可：

1. **材质过渡**（草→土路→石地→水）用自动拼接，边缘是渐变的，不是方块对缝；
2. **变体成片**：同一种地面按低频噪声连成一片（一片深草、一片浅草），**不要逐格随机**；
3. **贴地装饰**（decal）打散重复感，密度按噪声控制，路上不长草；
4. **树石遮挡**：大树/巨石/断墙按 y 排序盖住角色，画面才有纵深。

#### 3.1a `terrain-<theme>.png` — 512×512，16×16 格，每格 32px

`ID = row × 16 + col`（沿用 `tiles.js` 的 `col = ID & 0x0F`、`row = ID >> 4`）。区域固定，不许挪：

**自动拼接规则（和 `tiles.js` 现有掩码同一套）**：
掩码 = 这一格四周哪些邻居是**同一种材质**，越界当"不是"。

- `mask = 15` → 内部格，只画 base，不画边；
- `mask = 0` → 孤立一小块（水洼/土坑）；
- 1/2/4/8 → 单边；3/6/12/9 → 外角；其余 → 直边组合；
- **内凹角**：某个角的两条邻边都是同材质、对角不是，就叠一张 `inner` 补片。
  少了这一步，路口和池塘拐角会露出直角方块，一眼假。

#### 3.1d 地形怎么生成（不改地图数据的做法）

**A 阶段（先做，碰撞不动）**

- 进房时用 `seed ^ roomId` 生成一张 `terrain[y][x]`（只存在内存，不进存档，不改 `map` 的 0/1/2）；
- **路径**：从每个门 + 房间中心做 BFS，沿线刻 1–2 格宽的土路，带一点抖动；保证门到中心一定连通；
- **湿地**：低频 value noise 取低洼处，生成 2–5 格的水洼，避开路径 2 格；
- **装饰**：`hash(x,y,seed)` 撒，路上不长草、水边多石头；
- **墙**：现有的 0/1 墙格按掩码换新墙图；地图最外圈画"图外森林/岩壁"，不要直接切到天空色；
- **树**：只放墙格和图外圈（走不到），但要按 y 排序画树冠，角色贴边走过时会被树叶盖住 —— 这一下就不像棋盘了。

**B 阶段（A 跑通后再做，改碰撞）**

- 深水、悬崖、大树/巨石进入可走区，`canStep` / `isWall` / `bfs` 要把它们当障碍；
- 洞穴轮廓改用元胞自动机（不规则洞窟），房间尺寸不变；
- 测试要同步补：地形确定性、路径连通性、水/树不可走、388 项基线不许回归。

> ⚠️ 顺序不能反：先让 A 阶段在真浏览器里看着像一张地图，再动碰撞。A 阶段 `test-game.mjs` **必须原样 388 项全过**。

#### 3.1e "像地图"验收（人工看，缺一条打回）

- 随机截 3 张 720×1120 的游戏图，遮住 UI，**看不出 32px 格子**；
- 路的尽头一定通向门或空地，**没有断头路**；
- 水/湿地有岸线过渡，**没有直角方块**；
- 同一张瓦片**不会连续铺成 3×3 以上**；
- 角色走到树后，**树冠确实盖住他**；
- 地图外圈是森林/岩壁，**不是直接切到天空色**。

> 现状：`TILEMAP.theme` 写死 `cave`，`THEME_OF_ROOM` 还没做（瓦片计划 M1.66）。三套地形出完要顺手补主题切换，否则 field / waste 永远不显示。
> 旧 `tiles.js` 的 `ATLAS` 只有 floor/wall/door/decor，**要按上面的区域表重写成 v2**（见 §5.3）。

### 5.2 加载器 API（必须长这样，别的模块只认这套）

```js
DL.Assets = {
  ROOT: 'assets/',
  SHEETS: {
    player:   { src: 'chars/player-bean.png', cell: 128, cols: 4, rows: 5 },
    mobs:     { src: 'chars/mobs.png',        cell: 96,  cols: 8, rows: 7 },
    terrain:  { src: 'terrain/terrain-field.png', cell: 32, cols: 16, rows: 16 },
    props:    { src: 'props/props-field.png',     cell: 64, cols: 8,  rows: 8 },
    trees:    { src: 'trees/trees-field.png',     cell: 192, cols: 4, rows: 4 },
    // ...
  },
  load(cb),                 // 逐张 Image()，单张 404 只记 warn，不抛错、不阻塞
  ready(key),               // 这张图加载好了没
  image(key),               // HTMLImageElement
  draw(key, index, x, y, opt) // opt: { w, h, anchorX, anchorY, alpha, flip }
};
```

**硬要求**：
- `onerror` 不抛异常，`ready(key)` 保持 `false`；
- 全部加载完才 `cb(true)`，失败也给 `cb(false)`；
- 不在每帧 `new Image()` / `createImageBitmap`；
- `draw()` 里 `dx/dy` 取整，`flip` 用 `ctx.scale(-1,1)` 包一层。

```js
// 1) 底：base 变体按低频噪声成片选，不要逐格随机
const v = DL.Tiles.baseVariant(x, y, seed, 16);      // 0..15
blit('terrain', v, sx, sy);

// 2) 过渡：同一套 4 位掩码，四种材质各查一张表
const mask = DL.Tiles.maskOf(terrain, x, y, MAT.DIRT);
if (mask !== 15) blit('terrain', REGION.pathEdge + mask, sx, sy);
for (const corner of DL.Tiles.innerCorners(terrain, x, y, MAT.DIRT)) {
  blit('terrain', REGION.pathInner + corner, sx, sy);   // 0..3
}

// 3) 装饰：按 hash 撒，避开路/水
// 4) 整图预渲染到离屏 canvas，每帧只 1 次 drawImage（26×26 = 832×832）
```

### 5.7 性能

- 浏览器吃的是解码后的像素（宽 × 高 × 4），不是 PNG 有多小。磁盘全套可以到 100 MB，这是天花板；画布仍按 §1.3，不放大格子。

- `imageSmoothingEnabled`：地形 `false`，实体/道具/树/UI `true`，**每帧显式设**。
