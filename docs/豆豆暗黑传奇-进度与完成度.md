# 豆豆暗黑传奇 · 进度与完成度记录

> 日期：2026-10-21

## 一句话

**核心循环**：挂机升级 → 经验墙 → 等精英/稀有/BOSS 换装 → 再挂机。靠近商人按空格或点「交谈」开商店；E 挂机。

## 本轮（M1.40）

- 底材改为**固定 ilvl**：每槽每 10 级 3 档（1/5/10、11/15/20…），裁决之刃 Lv.30、屠龙 Lv.40
- 怪等级只决定掉“≤ 怪等级”的最高档；同名底材只有一个 ilvl，不会 Lv.8/Lv.9 并存
- 掉落、穿戴、商店、旧档兼容走同一套底材表

## 核心循环

```
挂机刷普通/精英（与手打同经验金币，只捡≤B）
        ↓
顶栏：精英保底还差 N · 稀有保底还差 M（阈值每周期随机）
        ↓ 稀有刷出 → 只提示不关挂 → 玩家自己关挂 → 手打拿 A
BOSS CD 到 → 顶栏提示手打换装
        ↓
再开挂机
```

## 关键数值

| 项 | 值 |
|---|---|
| 精英保底 | 每周期随机 1～**50** 只必出（上限 2） |
| 稀有保底 | 每周期随机 1～**200** 只必出（上限 1） |
| 挂机折扣 | **无**（靠等级差惩罚） |
| 升级 | `180 × 1.20^(L-1)` |
| 普通怪金币 | 高≥5 半、≥10 零 |
| 经验墙 | 高≥4 全怪 0 经验 |
| 装备槽 | 见 R7.1b |
