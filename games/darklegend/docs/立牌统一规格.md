# 立牌规格 · 角色 / 树 / 怪

> 上位：`docs/渲染规格.md`。  
> **立牌只管能动的生物和有机树冠。房子 / 摊 / 井 / 渔屋不在本文件——那些走 `build-house.js` 体积。**

---

## 〇、定案

| 项 | 结论 |
|---|---|
| 谁用立牌 | 主角、NPC、怪、椰子树、边界树、袋子、传送门特效 |
| 谁不用立牌 | 铺子、渔屋、摊位、水井、篝火、路灯、栅栏等环境 |
| 真身 | `games/darklegend/src/hd-draw.js` |
| 视角 | mir；板面后仰见 `render-three` 的 `TILT` |
| 影子 | 引擎接触阴影；画布里不画脚下影 |

---

## 一、硬规则

1. 角度对齐 mir（看得见头顶一圈）
2. 主光左上亮、右下暗
3. 画布无脚下影、无地面
4. 童话哑光色块
5. 角色 **3 头身**

---

## 二、世界高（约）

| 资产 | 世界高 |
|---|---|
| 主角 | ~2.15 |
| NPC | 略矮 |
| 小怪 | 按阶梯 |
| 椰子树 | ~7.3 |

---

## 三、改法

改 `hd-draw.js` → `npm run dev` 看 → 主人验收。不接 PNG / 生图。

---

## 四、验收

- [ ] 看得见头顶 / 肩顶
- [ ] 光向与场景一致
- [ ] 无脚下影、无地面
- [ ] 缩到游戏尺寸仍认得
- [ ] 与体积房子同屏不打架（色板）
