# 立牌规格 · 3D 素材 + 2.5D 固定视角

> 2026-10-29 定案。上位文件 `docs/渲染规格.md`，冲突以那份的长处为准、以本文的新口径为准。
> 一句话：**素材是 3D 渲染出来的，世界是 2.5D 固定视角——两条合起来才叫对。**

---

## 〇、定案（这条别再翻）

| 项 | 结论 |
|---|---|
| 素材 | **3D 渲染**（有体积、有材质、有顶面），不是平涂贴纸 |
| 视角 | **2.5D 固定**：45° 俯视、正交、不旋转 |
| 统一从哪来 | 同一束光 + 同一个材质 + 同一个体积语言。**不是靠调色** |
| 谁画影子 | **引擎**。素材里不许带影子、不许带地面 |

**为什么不是平涂**：平涂贴纸没有顶面和暗面，只能靠描边撑轮廓；站在有光的地面上，它永远是"贴上去的"。3D 渲染自带体积，缩到 112px 也读得出圆、亮、暗。

---

## 一、五条硬规则

1. **视角固定 45° 俯视**
   出图必须是 `high angle, camera looking down ~45°`：看得见**头顶一圈**和**肩膀的顶面**。
   平视正面（眼睛在正中、看不见头顶）在 2.5D 里有"贴墙"的感觉，不收。
2. **一个主光，方向右下落**
   主光左上（约 az −32°、仰角 34°），补光冷、很弱。所有资产的亮面在左上、暗面在右下。
3. **素材里没有影子、没有地面**
   `no cast shadow / no ground / no grass patch`。脚下那团洋红投影是把整张图弄脏的第一元凶，抠图时还得专门剥（见 §四）。
4. **一套材质**
   哑光黏土/树脂那一路，微反光但不要镜面金属。不要一半哑光一半亮面。
5. **比例不变**
   角色 3 头身、建筑 Q 版矮胖。世界高常量照旧（`render-three.js` 的 `TREE_H/HOUSE_H/STALL_H`）。

## 二、一把尺子（源图高 = 世界高 × 48 × 2.5）

| 资产 | 世界高 | 屏幕高 | 源图应有高 |
|---|---|---|---|
| 主角 | 2.34 | 112px | 280 |
| NPC | 2.05 | 98px | 245 |
| 鸡 | 1.45 | 70px | 175 |
| 摊位 | 3.0 | 144px | 360 |
| 房子 | 4.8 | 230px | 575 |
| 树 | 11.7 | 562px | 1400 |

**出图给 1024² 就够，抠完缩到上表尺寸。** 屏幕只有 112px 的东西，别堆碎细节——**大色块、少纹理**，靠体积和明暗读。

```text
{主体},
single key light from upper-left, soft cool fill light, warm key,
no cast shadow, no ground, no grass patch, no watermark,
solid magenta background (#FF00FF), single object centered, no text, 1024x1024
```

| 资产 | {主体} |
|---|---|
| 主角 | `chibi girl 3 heads tall, brown bob hair, green pinafore dress with white collar, brown loafers, idle pose` |
| 主角·招式 | 同上 + `{attack pose}`（蓄力 / 挥出 / 收招 各一张，**同一个角色，不改发型和衣服**） |

**四条不许删**：`high angle 45-degree`、`single key light from upper-left`、`no cast shadow / no ground`、`solid magenta background`。

## 四、入库流水线

```text
豆包出图（1024²、洋红底、无影无地）
  → python tools/ingest-3d.py 原图.png 输出.png --world 2.34
        · 按色相抠洋红（皮肤/鞋子不会误伤）
        · 顺带剥掉烘死的投影 + 右下角水印
        · 去粉边、缩到 2.5× 屏高、锚点对齐脚底
  → 浏览器 ?iso=unified 对拍（bench-scene.html 有滑杆）
  → 拍板后覆盖 assets/iso/processed/
```

抠图为什么按色相：这批图的背景和投影都是**洋红（色相 300±20、饱和 >0.45）**，而皮肤 342/0.19、鞋 332、裙子 126 都在窗口外。按"边框均值 + 容差"抠（`tools/prep-sprite.py` 的老办法）会把整张带粉调的脸一起削掉——这个坑已经踩过。
