## 一、核心循环

```
准备（时间冻结：拖人/合成/刷新）
  → 开战（自动攻击，关键波次可长按放主动技能）
  → 清波 / 漏怪扣血
  → 过关三选一强化（攻击/攻速/金币等）
  → 回准备，金币产出、放下一个角色/面板
  → 重复，直到通关或基地血空
```

`[官方][评测]` 确认：合并（merge）+ 塔防 + 背包格子 + 100+ 关卡 + 5+ 休闲小游戏。

## 三、和原版对齐的关键差异（复刻清单）

按「先抄」排序，前四条是原版有、我们没有的：

1. **单位有生命、会被打死**。原版僵尸会围上来打人，前排角色会死，所以才有「肉盾/医生/工程师」的配置意义。我们现在的敌人只会走向基地，单位永远安全——整个职责体系建立不起来就是卡在这。
2. **敌人会攻击单位，不只会走向基地**。
3. **兵种分工**：医务兵（治疗）、工程师（护甲恢复）、战争顾问（产银币）、鼓号队（充能/加速）、地雷专家（预放陷阱）、激光射手（蓄力穿透）、迫击炮手（范围+重伤）、轰炸指挥员（眩晕）。
4. **透明面板 = 格子扩展道具**，不是「清波自动解锁」。
5. **主动技能**：关键波次长按，耗能量。
6. **BOSS 生成**：土豆巨人（高防）、刺客（高机动）。
7. **局外**：碎片升星 + 章节解锁。

## 四、数值（原版没拿到，别编）

原版的具体数值（每波人数、血量曲线、金币产出）**没有可靠来源**，复刻时自定，但**结构要一致**：金币产出 → 刷新 → 合成 → 波次递增。

我们现有 `TUNE`（`squad.js:69`）可以沿用，复刻时按「一局 3~5 分钟 / 15 波」的节奏调。

## 五、18touch 那篇的坑（提醒）

该页后半段混进了**别的游戏**的攻略（营火、吊桥、木材/石材采集、岛屿）——那是《This War of Mine》一类生存游戏的内容，**不是本作**。以后查攻略遇到「采集/建造/营火」直接跳过。

## 六、结论

原版的「核」是：**背包格子 + 合成 + 单位会死 + 分工**。

我们现在有前两个，缺后两个。**先补「单位会死 + 敌人会打人」，分工才有意义**——这是 1:1 复刻的第一步，也是整个职责体系的地基。
