# 游戏效果手册（手感 / juice）

> 2026-11-16 建。**适用范围：DDGame 全部 Canvas 游戏**。零依赖、纯 Canvas 2D，可以直接抄。
> 配套实验台：`tmp/effect-lab/index.html`（双击就开，点角色或按 1/2/3）。
> 方法论来源见文末。
>
> **2026-11-16 修订（主人以玩家身份叫停）**：**全屏震屏 + 全屏白闪 = 坏设计，默认关。**
> 理由：玩家注意力是锁在目标上的聚光灯，全屏抖/闪会**强行把它掰走**——厌恶来自"控制感被打断"，不只是视觉不适；另外还有晕动/光敏风险。
> 打击感改放局部：**hitstop、受击目标闪白、squash、粒子、飘字、音效**。
> 下文涉及"全屏震/闪"的参数只作"想开的人"的对照，不是推荐。

---

## 〇、一句话

> **一次"打中了"，不是加一个特效，是 100ms 内叠 5~8 个微反馈。**
> 单个都便宜，叠起来才读得出"重"。

---

## 一、四条铁律

1. **叠，不是换**——声音、粒子、冻结、局部闪白、击退、飘字，一起发。
2. **夸张要短暂，会回到静止**——不衰减的放大/抖动会变成"新常态"，就不再是反馈了。
3. **按重要性分档**——脚步和 Boss 死亡不能一个力度。全游戏用同一套三档预设，才不会又死又吵。
4. **加在焦点上，别抢视野**——玩家注意力锁在目标身上；全屏抖/闪是强行把聚光灯掰走。反馈都落在受击目标身上；hitstop 安全，因为它不移动视野。

---

## 二、三档预设（照抄，别每次现调）

| 通道 | small | medium | large |
|---|---|---|---|
| hitstop | 0 | 0.04~0.06s | 0.10~0.15s |
| 粒子 | 4~6 颗，小、白/浅色 | 10~14 颗，中、暖橙 | 26~40 颗，大、金色、**带拖尾** |
| 受击目标闪白 | 无 | 短闪 1 帧 | 闪 2~3 帧 |
| squash | 1.1 倍 | 1.3 倍 | 1.5 倍 |
| 击退 | 无 | 6~10px | 14~20px |
| 冲击环 | 无 | 无 | **有**（扩散圆环） |
| 飘字 | 小、白 | 中、白 | 大、金色、弹入 |
| 全屏震/闪 | 关 | 关 | 关（可选开） |

**规则：三档至少要在 3 个通道上拉开**（比如冻结 + 粒子 + 击退），只改一个数字玩家分不出来。实验台就是按这张表实现的，可以直接对照。

**事件先归到档，再由档决定参数**，不要在每处命中写死数值。

## 三、反馈菜单（每样怎么调）

### 1. 全屏震屏：默认关（玩家视角的坏设计）

**先给结论：DDGame 默认不抖屏幕。** 想开的人再走下面的对照实现。

- 坏在哪：挡读屏（塔防 / 节奏要看全场）、晕动、光敏；它给的"重"有更便宜的替代。
- 替身：受击角色**局部抖**（只抖那一个精灵，幅度 3~6px、0.1~0.2s）、hitstop、闪白、squash。
- 如果仍要开（开关默认关）：`trauma ∈ [0,1]`，事件**加**，线性衰减 1.0~1.5/秒；位移 = `trauma²` × 双正弦采样 `0.6*sin(t*11)+0.4*sin(t*23)`；上限 8~16px / 0.05~0.12 rad；**只抖相机，不抖玩家本体**；**绝不每帧 `rand()`**。

### 2. hitstop（顿帧）

- 命中瞬间把**游戏时间**压到 0.05 倍，持续 0.04~0.15 秒真实时间。
- 计时必须用**真实时间**（`requestAnimationFrame` 的 dt），不能用被压慢的游戏时间倒计，否则永远解不开。
- 只冻结世界；**若开了全屏震/闪**，它们用真实时间继续走，冻结期间画面仍有冲击（默认关则无此问题）。
- 只对"打中的那一下"触发一次，不要每次挥砍都冻。

### 3. 受击闪白

- 命中 1~3 帧把目标整体染白（`fillStyle` 直接换白，或用 `globalAlpha` 叠白），快速衰减。
- 最便宜、最清楚的"打到了"信号，比粒子还先被看到。

### 4. squash & stretch（形变）

- 事件瞬间：受击 `scale(1.3, 0.72)`，起跳 `scale(0.84, 1.24)`，落地 `scale(1.32, 0.7)`。
- 然后**弹簧回弹**（目标 1，k≈130、阻尼 c≈14），会过冲一点，卡通感就出来了。
- 线性回弹会显得"机器人"，尽量用弹簧或 `easeOutBack`。

### 5. 粒子

- 命中点爆发，**朝四周 + 少量上抛**，方块/星形混着来，比纯圆点有层次。
- 池化（对象池或上限截断），别每次命中 new 一堆。
- 生命 0.25~0.6s，带重力和阻尼；**hitstop 期间粒子也该冻住**（用游戏时间更新）。
- 颜色跟事件走：普攻白/暖橙，暴击金，受伤红。

### 6. 飘字

- 弹入：`easeOutBack` 从 0.4 放到 1（约 0.14s）；上浮 + 重力，0.8~0.95s 消失。
- 水平随机漂移，连击才不会叠成一坨；AOE 同色数字可以合并（hero 已经做了）。
- 暴击更大、金色、带描边。

### 7. 全屏白闪 / 冲击帧：默认关（同上，坏设计）

**DDGame 默认不闪全屏。** 受击目标自己闪白才是对的做法：

- 局部闪白：只把被击中的目标染白 1~2 帧，快速衰减——最便宜、最清楚，也不伤眼。
- 全屏白闪 / 冲击帧（对照用，默认关）：半透明反色 `alpha≈0.65` 或 `lighter` 白 0.05~0.1s；不推荐在竖屏塔防 / 节奏里开。
- 局部缩放脉冲（也慎用）：只作大事件的可选小点缀，+2%~4%。

### 8. 缓动（所有 UI/位移都要过曲线）

| 用法 | 曲线 |
|---|---|
| 弹入 / pop | `outBack`（过冲） |
| 回正 / 停下 | `outCubic` |
| 镜头平滑移动 | `inOutSine` |
| 蓄力 / 起手 | `inCubic` |

## 四、DDGame 现状盘点（2026-11-16）

| 游戏 | 已有 | 缺 |
|---|---|---|
| `hero` | hitstop（dt×0.16，正确用真实时间倒计）、shake、puff、飘字合并 | 局部反馈原语、受击闪白、squash、缓动 |
| `doudou` | 粒子 + impactSparks（大颗 + 拖尾 + 中心亮核）、shake、飘字抛物线 | hitstop、局部闪白、squash |
| `wordtower` | 粒子、shake、闪电 | 命中冻结、闪白、档位 |
| `zombie` | shake（到位就衰减） | 粒子、hitstop、闪白 |
| 共同 | — | **三档预设、局部反馈原语、统一缓动、无障碍开关（全屏震/闪默认关）** |

**结论：不是缺特效，是缺「档位 + 局部反馈原语」。** 各游戏自己搓，力度和手感不一致；而且别把反馈升级成全屏震/闪。

## 五、零依赖模板（可直接抄）

完整实现见 `tmp/effect-lab/lab.js`，这里只给核心几段。

```js
// ---- 全屏震屏（默认关，仅开关打开时用；完整实现见 lab.js）----
trauma = Math.min(1, trauma + add);              // 事件加
trauma = Math.max(0, trauma - 1.2 * rawDt);      // 真实时间衰减
const shake = trauma * trauma;                   // 平方
shakeT += rawDt * 30;
const ox = 14 * shake * (0.6*Math.sin(shakeT*1.7) + 0.4*Math.sin(shakeT*2.3));
const oy = 10 * shake * (0.6*Math.sin(shakeT*2.1) + 0.4*Math.sin(shakeT*1.3));

// ---- hitstop ----
let dt = rawDt;
if (hitstop > 0) { hitstop -= rawDt; dt = rawDt * 0.05; }   // 真实时间倒计

// ---- squash 弹簧 ----
svx += (1 - squashX) * 130 * rawDt - svx * 14 * rawDt;
squashX += svx * rawDt;      // squashY 同理

// ---- 缓动 ----
const outBack = t => 1 + 2.70158*Math.pow(t-1,3) - 1.70158*Math.pow(t-1,2);

// ---- 反馈分档 ----
const TIER = {
  small:  { trauma:0.16, hitstop:0,    n:4,  flash:0    },
  medium: { trauma:0.42, hitstop:0.05, n:10, flash:0.22 },
  large:  { trauma:0.85, hitstop:0.13, n:30, flash:0.55 },
};
```

## 六、雷区（踩了就白做）

1. **抖玩家本体**而不是相机 → 碰撞/瞄准错位。
2. **每帧 `Math.random()` 抖屏** → 电噪感，不是震。
3. **hitstop 用被压慢的时间倒计** → 永远解不开。
4. **线性 tween 到处用** → 机器人味。
5. **夸张不衰减 / 永久放大** → 变成新常态，反馈失效。
6. **每个脚步都重击** → 晕、吵、真重击被淹没。
7. **冻结太长卡输入** → 手感发涩；juice 必须短、且允许输入缓冲。
8. **重击反色拉满 + 白闪拉满 + 缩放拉满** → 光敏不适，也会闪瞎自己。
9. **把全屏震屏 / 全屏闪当默认反馈** → 挡读屏、晕动；DDGame 默认关，别偷偷开回来。

## 七、验收清单（改完照着看）

- [ ] 轻/中/重三档，力度能一眼分出来
- [ ] 重击有 hitstop + 局部闪白 + squash + 粒子，且 0.3s 内回到静止
- [ ] 默认没有全屏震屏 / 全屏闪屏（两个开关都是关）
- [ ] （若开）震屏是相机偏移，角色碰撞没变
- [ ] 冻结期间输入仍然响应（不卡手）
- [ ] 粒子/飘字不叠屏（有上限）
- [ ] 60fps 稳（粒子池、不用 shadowBlur 做光晕）
- [ ] 减震 / 减闪 两个开关真的能关

---

## 八、无障碍（必须留给玩家）

- **全屏震屏 / 全屏闪屏默认关**；想开的人自己开，开关状态存本地。
- 开了之后也要给减弱档（trauma ×0.35；闪屏换静态染色）。
- 更稳的做法：干脆只做局部反馈，这两项不实现。
