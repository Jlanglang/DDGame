## 一句话

从"开放大地图赶路"改成 **"主城 + N 个小世界房间"**：进门即战，没有赶路。
代码拆成 `data / core / world / combat` 四层，渲染拆成 6 层，布局改为 **canvas 铺满 + UI 浮层**。

## 架构

```
data.js     表与常量（怪物 / 装备名 / 商店 / 房间配置）
core.js     随机 / 格子工具 / 装备属性 / 成长公式（纯函数）
world.js    主城 + 房间生成 / 碰撞 / 视野 / BFS   ← 换地图形态只改这里
combat.js   伤害 / 范围 / 目标 / 怪物行为         ← 调战斗只改这里
game.js     编排 + 6 个渲染层 + UI + 输入 + 存档
```

**替换成本**：换地图 → `world.js`（136 行）；调战斗 → `combat.js`（91 行）；调数值 → `data.js + core.js`。

## 本轮关键教训

- **纯色块 + 开放大地图 = 纯赶路**：移动没有产出，情绪价值极低 → 切成小世界
- **canvas 是位图，CSS 拉伸必变形**：等比缩放 + dpr 才是正解
- **相机永远追人，不追地图**：`camTarget` 夹取对任何地图尺寸通用
- **渲染分了 3 层，布局也要分 3 层**：canvas 铺底、UI 浮层，否则地图被挤小
