## 一、五条基石（不可动摇）

| # | 基石 | 含义 |
|---|---|---|
| 1 | **mir 俯视** | 固定相机：**yaw0° / pitch55° / 透视 fov32 / zoom1.70**（一屏竖向 ≈20 格）；不旋转、不平视 |
| 2 | **2.5D + 童话风** | 斜俯视的可信世界；**休闲、童话、轻松**，画面语言学传奇角度，不做传奇写实 |
| 3 | **玩法 / 数值不动** | 战斗、掉落、商店、任务、升级曲线一行不改 |
| 4 | **可信感** | 投影一致、有影子、一套色板、有层次、不违和。**不是物理真实光照** |
| 5 | **Three.js** | 透视相机 + 2D 立牌精灵，纯静态网页，双击能跑 |

**基石之上的都可以谈；基石本身不再讨论。**

**地面 v2 的账**（2026-10-28 夜）：

- 旧地面贴图只有 **6px/格**（`iso-ground.js` 的 `scale = 6`），24 格贴图 144px，放大 8 倍铺屏幕 —— 这是「糊一层」最硬的那条
- 新 `iso-art.js`：**48px/格**（1152²），8 种材质分底材/覆盖层，覆盖层用圆角矩形+小凸起做有机边

**诚实结论**：工程骨架（影子 / 排序 / 性能 / 测试）到位；**画面语言还没对上规格**——连续贴图消了棋盘格，也消掉了「菱形瓦片」本身。主人已有新思路，下一轮按新思路开，不必在连续贴图上继续抠。

### 地面分块：实测数字（headless + 软件画布，真机约快 2~3×）

| 事实 | 数 |
|---|---|
| 53×53 @48px 整张 | **505 ms**（bench）/ 544 ms（旧版进房间实测） |
| 一块 16 格（含 1 格出血） | **63 ms**（bench，9 次里最慢 138 ms） |
| 块大小对比（53×53，同一张图） | 24 格：均 149 / 峰 342；**16 格：均 79 / 峰 138**；12 格：均 48 / 峰 91 |
| 出血的代价 | 画格数 ×1.24（16 格块） |
| 拼回去 vs 整张 | 平均差 **2.14 / 255**（只剩按画布撒的草簇碎石） |
| 缝 | 三条内部缝 ×0.81 / ×0.96 / ×0.96（缝带差 ≤ 块内，**无缝**）；关掉出血是 ×1.31 |

三条踩过的坑（别再踩）：
- **按格锚定的东西必须减窗口原点**：`stampBlob` / `detailOnOverlay` / `shoreEdge` 原来画 `gx*px`，整张图时画布坐标 == 世界坐标所以看不出；分块后整层覆盖物被平移 x0*px，缝上是一条硬线（实测跨缝跳变 ×3.3）。
- **低频色斑不能按画布撒**：0.5~2.5 格半径、alpha 0.1~0.3 的色斑是一块地面的"调子"，换块就断，缝上会出现一条 3% 的调子台阶（列均 160.8→156.0）。现在按整张图撒点、窗口外的跳过（`blobSpace`），整张图和任何一块**逐像素一致**。
- **判据不能是"缝那一列的亮度"**：整高平均会把只在路口出现的一小段缝冲淡到 0。现在用"缝带 vs 块内，各自与整张图的差"（验收台 ⑥）。

### 光照这条的三个结论（别再踩）

| # | 结论 | 说明 |
|---|---|---|
| 1 | **光强是物理单位** | 新版 three 的 `intensity` 不比老教程（不再 ×π）。按老数值配，画面会整片发灰，看起来像"灯坏了"——实际只是不够亮。地面对照：`AmbientLight 2.6 + DirectionalLight 4.2` 才等于贴图原色 |
| 2 | **人物阴影是剪影投影，不是脚下椭圆** | 椭圆是"接触阴影"，看得出是块贴纸；正确做法是把人物贴图按光向压倒在地面（顶点坐标：`x' = x + t·kx, z' = t·kz`，t 是高度）。这样连武器、裙摆的影子都在。参考图（传奇女英雄）就是这种 |
| 3 | **阴影要开 `normalBias` | 不开的话 shadow acne 会把整片地面压灰，看起来像"材质脏了" |
