# 角色设定 · 豆豆与头身比

> **2026-10-28 定案**：豆豆**不是豆子**，是一个 **2 头身的小女孩**（栗棕卷发、墨绿白领、空手。
> 本文是角色资产的**唯一判据**——出图、验收、AI 生成都以本文为准。
> 配套：`docs/渲染规格.md`（投影 / 色板 / 瓦片）、`docs/STATUS.md`（进度）

---

## 一句话

**2 头身是动作可能性的前提，不是审美偏好。**
头不能独立动，就做不出「头侧前倾 + 躯干旋转 + 手伸出」那一刀。

---

## 一、豆豆是谁（三条判据）

只要这三条对上，就是她；细节丢了还是她。

| # | 判据 | 具体 |
|---|---|---|
| 1 | **剪影** | 齐肩厚发、中分八字刘海、发尾外翻 |
| 2 | **脸** | 大棕瞳、粗上眼线、大腮红、单线小笑 |
| 3 | **衣服** | 墨绿短袖 + 白色圆领（彼得潘领）+ 白袖口 |

### 明确放弃（别再生成）

- **道具**：手电筒等一律不要，空手；攻击动作用推 / 拍，不用武器
- **发丝细节**：不画分层发丝，只留 2~3 条内线 + 外翻剪影
- **碎花**：雏菊从满身碎花降到 3~5 朵大的
- **长发过肩**：必须留出颈线，头发下缘不得压住肩线

---

## 二、头身比（硬约束）

| 类别 | 头身比 | 说明 |
|---|---|---|
| 主角（豆豆） | **2.0 ± 0.15** | 头 ≈ 全高一半，全套美术的「尺」 |
| 小怪 | 2.0 ~ 2.5 | 与主角同一卡通语言 |
| 精英 | 2.5 ~ 3.0 | **加宽，不加长** |
| BOSS | 3.0 ~ 4.0，**上限 4** | 气势靠体宽（≈ 主角 2.5 倍）、占地、特效 |

**量法**：`头身比 = (脚底 y − 头顶 y) ÷ (下巴 y − 头顶 y)`，在透明边界上量，超差 ±0.15 打回。

**为什么上限是 4**：

- 超过 4 头身会滑向「人形」，跟 2 头身主角不在同一个卡通语言里；
- BOSS 的身高只 +30~50%，再高镜头必须拉远，主角反而变小，气势是负的。

> **例外**：`games/cardfight` 的卡牌立绘是 **4 / 6 头身**，属于「海报」轴，**不适用本文**。
> 立绘是海报，精灵是棋子，两套比例明文分开，不要互相套用。

## 三、拆件（纸娃娃）

| 件 | 数量 | 必须能动的部分 |
|---|---|---|
| 头（含脸） | 1 | 转、侧倾、滞后 |
| 头发 | 2（前刘海 / 后发） | 甩、滞后（与头不同相位） |
| 躯干 | 1 | 倾、旋转（靠肩线斜 + 前后错位 + 变窄） |
| 上臂 / 前臂 | 2 × 2 | **前臂必须独立**，否则「手伸出去」只能整体前倾 |
| 腿 | 2 | 前后摆 |
| 脚 | 2 | 触地锁死，不滑 |

**头与躯干必须在剪影上分离**：脖子要能看见。这是 2 头身唯一真正的设计冲突，必须在设计阶段解决，不能指望出图时撞运气。

### 4.3 负面词（两版都加）

```text
realistic proportions, 4-head-tall, 6-head-tall, long legs, slender body,
long flowing hair covering shoulders, hair below chin, necklace, hat,
flashlight, weapon, extra fingers, perspective, side view, cropped feet,
multiple characters, text, watermark, gradient background, soft shadow
```

> `hair covering shoulders` / `hair below chin` 这两条最关键——防模型自动把头发拉长，把颈线吃掉。

### 4.4 出一批只看三件事

1. **颈线**：头发下缘有没有离开肩线
2. **比例**：头是不是全高一半，腿是不是短粗
3. **三件套**：八字刘海、白圆领、墨绿

三条全过才算「能用」。过两条就重出，别将就——将就的那版会成为以后所有资产的样板错误。

## 五、64px 减法规则

游戏内角色 64×64 逻辑像素，头约 32px，脸约 20×20。

| 元素 | 64px 下 | 处置 |
|---|---|---|
| 大眼睛（占脸 40%） | 每只约 6px | **保留**，靠位置和眼线读数 |
| 头发高光 / 发丝分层 | 2~3px 碎光 | **全丢**，改大色块 + 2 条内线 |
| 雏菊碎花 | 1~2px | **全丢**，3~5 朵大花 |
| 白领 | 6~8px 带宽 | **保留**，是判据 |
| 腮红 | 4px 色块 | **保留**，是判据 |

**规则**：源图 1024 → 缩到 128 源帧 → 游戏内按 64 绘制。**不要直接把 1024 缩到 64。**

## 七、迁移顺序

1. **只做一个方向、九帧**：idle 2 + walk 4 + attack 3，正面偏左 3/4 视角，左右靠镜像
2. 九帧验收通过（颈线 / 比例 / 三件套 / 色板）
3. 再扩方向（5 方向）
4. 再扩角色（小怪 → 精英）
5. **最后才碰 BOSS**

**不要一次性生成 20 帧。** 一致性在 9 帧上崩掉，还来得及改；在 20 帧上崩掉，就是白干一晚上。
