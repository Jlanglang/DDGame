## 结构

```
准备（时间冻结）→ 3 个待命位（和战场同一套画法）→ 点/拖进格 → 开战 →
清场 → 免费自动刷一次 → 回准备。**杀怪攒经验，升级时弹三选一**；每关最多升 10 级。
每关 15 波；**漏一个怪就输**（没有基地血量）。通一关 → 点一下进下一关（进度存 localStorage）。第一世界共 5 关（10 关压成 1 个世界）。
```

**竖屏布局（2026-11-20 定版，720×1440 逻辑，1:2）**：

y 960..1030   下 1/3：顶部金币总额
y 1028..1228  3 个待命位（190×200，不是卡片；单位按战场画法站进去，框最长边适配 160）
y 1248..1358  刷新 / 开战 大按钮（110 高）
y 1380..1440  底部（← 库 / 经典 入口）

- **格子区占宽 40%、街道 60%**（2026-11-20 主人定，好算）：**5 列 × 7 行**、格 56、宽 280；
  格子区在战场里垂直居中（y 284..676）。单位直径约 38；敌人 r18（直径 36，和单位一个量级）、
  小 BOSS r26、大 BOSS r38（都能压过单位）。
- **格子卡（原版设计）**：开局只开**前排 3×3**（靠敌人来的右侧、行居中）；刷新会抽到 1/2/3/4 格的拼图块，
  拖到棋盘未解锁区域（形状完整、至少挨着已解锁区）就解锁。清波白送只给单位，格子卡得自己花钱刷。
- **待命区不是卡片**：3 个待命位，单位用**和战场完全相同的 `drawUnit`** 画（稀有度框 + 角标 + 枪管），
  按占格把框的最长边适配到 160（1×1 和 2×2 看着一样饱满）。占格看框形状，等级看框色 + 角标。
- 交战中待命区换成一条状态带（波次 + 场上敌人数），不放空位。
- 格子紧挨着画、不留缝；空格用棋盘色差分格；战场中段铺一条横向街道，格子压在路上。
- 顶栏右侧有 **倍速按钮 ×1 / ×2 / ×3**（点一下循环，只在战斗阶段生效，准备阶段时间照旧冻结）。
- 手机竖着拿：`#stage` 宽 `min(100vw, 100dvh*0.5)`、高 `min(100dvh, 100vw*2)`，基本铺满。

## 进度：第一世界 5 关 + 强化点分配（2026-11-20 v0.16）

- 这是**单机**，不是手游：**没有军功 / 抽奖 / 商店 / 内购**。
- **10 关内容同质，压成「第一世界 = 5 关」**：原来 10 关只是数字缩放，没有场景差异；
  现在 1 个世界 5 关，难度跨度保持原来 10 关的总量（`stageHpMul 1.24` → 第 5 关约 ×2.36）。
  世界 2 换场景 / 新兵种再做，`TUNE.worldName` 是场景名。
- **兵种解锁**：第 1 关 2 个（步枪 / 霰弹），之后每关 2 个，第 5 关 10 个全解锁（`KINDS[].unlock`）。
- **强化点**：每关首通发 `6 / 8 / 10 / 12 / 14`（合计 50），**重复通关不再发**。
- **1 点 = 1 级**（2026-11-20 主人拍板）：不再有固定等级加成，点数直接加到「攻击 / 血量 / 防御」三项之一；
  攻击 / 血量每点 +20% 兵种基数（面板显示成固定值，步枪 +1.0 攻击 / 重炮 +17），
  防御每点 +2% 减伤（和工程师光环合计封顶 45%）。
- **单项上限 10 点**：一个兵种三项全点满 30 点，10 兵种 300 点，实际只有 50 点 → **只够养 3 个左右，必须选**。
- **单兵加点上限**：按已通关数放 `4 / 8 / 12 / 16 / 20`（`TUNE.attrCapByCleared`）。
  两套门槛一起卡：点数卡「能不能全养」，上限卡「能不能攒点堆一个」。
- 局内金币只用于当局刷新 / 运营，不存档；输了就重打，进度和点数都不扣。
- **存档**：`doudou.squad.save.v4` = `{ v:4, highest, cleared[5], pts, attrs[10]{dmg,hp,def}, mastery[10], stats }`；
  v3（spent 等级点）/ v2 / v1 / 更旧 key 首次加载自动迁移，老档等级点全折算成攻击点，不吞进度。
- 养成面板点卡片进详情，底部是**三个加点按钮**（攻击 / 血量 / 防御，各 1 点）；到本世界上限显示「再通关 1 关放上限」。
- 结算页显示「首通 / 再次通关 · 强化点 +N · 已通关 n/5 · 强化点余额」。

## 金币：只有三个来源（2026-11-20 主人定）

1. **战争顾问上场**：每个顾问每秒 +0.35（**只在战斗阶段结算**，准备阶段时间冻结，一分钱不涨）。
2. **清一波**：`8 + 波数×2`。
3. **三选一补给**：抽到「获得 30 金币」。

没有基础每秒收入、没有打怪掉钱、没有开局自动涨——`TUNE.coinPerSec` 已删除。

## 每波结束自动免费刷一次

`settleWave()` 里 `G.wave++` 后调 `rollBench()`：待命区补候选（前 2 关 2 个，第 3 关起 3 个），
并把付费刷新计数归零（下一刷从 10 起价）。作用是白送一次 + 提醒玩家「这里可以刷新」。

## 战斗表现（2026-11-20 本轮）

- **伤害数字**：子弹命中就飘伤害值（暖白；3 星以上金色、5 星更大），溅射也会飘；
  总数限流 48 条，防止割草时刷屏。
- **弹道扫掠判定**：子弹按「上一帧 → 这一帧」的线段判定，不再只看落点。
  小怪 r=18、子弹一帧能飞十几像素，点判定会直接穿过去——**这就是「只有子弹没伤害」的根因**。
- **清波清场**：`settleWave()` 清空 `bullets / bits / floats / rings / enemies`，
  回准备时不留上一波的子弹和尸体。
- **战斗倍速 ×1/×2/×3**：`frame()` 里在战斗中多跑几步固定步长（不是把 dt 乘大），
  弹道和碰撞不会因为加速而穿透；准备阶段永远 1 步。

## 数值与数据层

**数值全在 `squad-data.js`**（零构建，`squad.html` 里排在 `squad.js` 前）：兵种 `KINDS`、
稀有度 `RARITY`、全局 `TUNE`、BOSS 参数 `BOSS`、波次曲线纯函数。
**`squad.js` 只读不写数值**——调平衡只动 data 文件，不碰逻辑。

> 2026-11-20 主人定：**难度先跳过，先把基础跑通**；数据暂时只保证「能玩、不卡死」，不再反复调。
> 2026-11-20 v0.11：数量改成「压力」不是难度旋钮（12 + 波数×3.4）；
> 难度改用**敌人血量 + 防御（armor）**拉，敌人也不再是小点（r=18）。
> 具体平衡等主人验收后再统一调。

| 档 | 1~5 星 | 颜色 | 视觉强度 |
|---|---|---|---|
| C | 1 星 | 白板 `#d3dbe6` | 细框，无光 |
| B | 2 星 | 蓝 `#4fb8f0` | 加粗 + 微光 |

### 波次与 BOSS（2026-11-20 v0.11）

- **每波敌人数** = `12 + 波数 × 3.4`（第 15 波 63 个）——数量是压力，不是难度旋钮。
- **敌人防御**：`armor = min(40%, 0.4%×波数 + 1.5%×关卡 + BOSS 加成)`，子弹和溅射都吃；
  越往后越硬，难度靠「血量 + 防御」拉（主人 2026-11-20 定）。
- **小 BOSS** 压第 **5 / 9 / 13** 波末尾（血 ×28、速 ×0.75、攻 ×1.5、r=26、armor 8%）；
  **大 BOSS** 压第 **20** 波末尾（血 ×60、速 ×0.6、攻 ×2.2、r=38、armor 18%）。
- **没有基地血量**：不管小兵还是 BOSS，漏到基地线当场判负——BOSS 也只是一只更难打的怪。
- BOSS 最后出场、不占小兵名额；进度条上 5/9/13 有紫三角、15 有红三角。

### 升级：杀怪升级，升级才弹三选一（2026-11-20 主人纠正）

- 原版不是按波数给三选一，是**杀僵尸攒经验升级**；每关最多升 10 级（2026-11-20 从 20 级降下来，弹窗太烦）。
- 经验：小兵 +1，BOSS +5；升到下一级需要 `18 + 当前等级×2`。
- 升级立刻暂停战斗，弹 3 张词条；选完回战斗。一次跨多级就排队逐个选。
- 词条池（`squad-data.js` 的 `AFFIX`）按等级解锁稀有度：
  - Lv1+ 普通：伤害 +20% / 攻速 +15% / 射程 +12% / 生命 +15% / 金币 +25
  - Lv4+ 稀有：伤害 +35% / 攻速 +25% / 射程 +20% / 生命 +25% / 弹道 +1 /
    穿透 +1 / 溅射 +20% / 治疗 +35% / 减伤 +30% / 产币 +35% / 攻速光环 +30% / 金币 +50
  - Lv7+ 史诗：伤害 +60% / 攻速 +40% / 射程 +30% / 生命 +35% / 弹道 +1 /

- 抽取按稀有度权重、同兵种同属性不重复；辅助位只会抽到自己的光环词条。
- 清波**不再弹三选一**，只回准备 + 免费刷新。

### 生命：单位会死，敌人会围上来打人

- 每个单位有血，**星级每升 1 星 +180% 血**，合成时回满。
- 敌人压到某个单位的格子右侧就**停下来啃它**（每秒 1 口），啃死之后继续走。
- 单位死了就从格子上消失（**不退回待命区**），战斗里也不能补——所以前排真的会空。
- 单位头顶有血条（受伤才显示，绿→黄→红），敌人啃人时身体前扑、带抓痕。
- 医生给队友回血但**不自奶**（否则一群医生会互相回成打不死的铁王八，模拟里真踩过）。

### 养成：属性加点（攻/血/防）+ 专精里程碑

- 每个兵种有**跨局保留**的三项属性点（存 `SAVE.attrs[i] = { dmg, hp, def }`，**1 点 = 1 级**）：
  攻击 / 血量每点 +20% 兵种基数（面板显示成固定值，步枪 +1.0 攻击 / 重炮 +17），
  防御每点 +2% 减伤（和工程师光环合计封顶 45%）。
- **合成上限 = 总加点**：0 点只能合 3 星，2 点开 4 星，4 点开 5 星。
- **专精里程碑按兵种分化**（`squad-data.js` 的 `MASTERY`，每兵种 4 个节点，独立花 `2/3/4/5` 点解锁）：

  - 重炮手：溅射范围 +25% / 伤害 +25% / 溅射范围 +25% / 伤害 +30%

  单项上限 10 点，单兵总数上限按通关数放（4/8/12/16/20），点数再多也越不过。
- **养成面板（v0.11 重做，v0.16 改成三属性加点）**：2 列 × 5 行卡片，每张有立绘位（程序化 Q 版，真图后接）、

## 操作（对齐原版）

- **点按**：点待命位 / 场上单位选中（脚下黄圈）→ 点空地/空格放过去；点同兵种同星 → 合成。
  点按和拖拽走**同一条落点逻辑**（`drop()`），大单位自动找最近的合法位置。
- **拖拽**：拖单位 → 格子放人；拖格子 → 换位 / 同款合成；**场上单位拖回待命位可以回收**（空位放，占用的位试合成）。
- **待命区是合成中转站，不保留**：场上单位拖回来自动合成；合完再拖上场。**开战和刷新时清空**。
- **刷新**：换掉整批候选（2/3 个），价格每次 +5（每波重置）；**每波结束免费刷一次**。
- 拖大单位有 **w×h 预览框**：绿=能放 / 金=能合 / 红=放不下。
- **倍速**：顶栏 ×1 / ×2 / ×3，点一下循环；只在战斗阶段生效，准备阶段时间冻结。
- 鼠标和触摸都走 Pointer Events，多指只认第一根；点击/拖拽用移动距离 10 CSS px 区分。

## 防腻：单机能做的（还没做，等主人拍板）

单机不靠货币和抽奖留人，靠「关卡 / 记录 / 自限玩法」：

1. **关卡选择**：现在只能顺着打；之后可以选已通关关卡重打，试阵容、刷最佳记录。
2. **每日挑战**：用日期做种子（同一天同一套），只存「今日最佳」和卡面标记，不发货币。
3. **开局契约**：进关前 3 选 1 个自限条件（敌人 +20% 血 / 少一个待命位 / 无医务），
   通关给「契约标记」和记录，不给数值。
4. **成就 / 图鉴**：首通、无阵亡、10 级满、单局击杀数等，纯收集。
5. **难度档**：同一关可选普通 / 困难，记录分开；不堆波数。

原则：**不加广告、不加抽奖、不做内购、不靠无限涨数值**；目标就是通关、记录、收集。
