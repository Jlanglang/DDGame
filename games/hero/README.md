# 豆豆勇者

> 枫之谷 / 冒险岛式横版动作的单机切片。零依赖、零构建，双击 `index.html` 就能玩。
> 独立项目，不放在 DDGame 里。**横屏 1280×720**，手机请横过来。

## 运行

- 直接双击 `index.html`（`file://` 可用）
- 或 `python -m http.server 3456`，打开 http://localhost:3456
- 手机：横屏打开，舞台保持 16:9，两侧自动留黑边；竖屏会提示旋转，也可以点「竖屏凑合玩」

## 操作

| 动作 | 手机 | 键盘 / 鼠标 |
|------|------|-------------|
| 左右跑 | 左下 WASD 方向键，或左手拖屏 | `A` / `D`，或用鼠标按住拖 |
| 跳 / 二段跳 | 左下 `W`，或右下「跳」 | `W` / `空格` / `↑` |
| 下平台 | 左下 `S` | `S` / `↓` |
| 普攻（三段连击） | 右下「攻击」，按住可连段 | `J` / `Z` |
| 旋风斩（8 秒 CD） | 右侧「旋风」 | `K` / `X` |
| 商店（安全区） | 靠近商人点「🛒 商店」 | `E` |
| 暂停 | 左上角 | `P` |
| 重开 | 右上角「重开」 | 结算面板「再来一局」 |

左下 WASD 是常驻的，半透明；键盘按下时对应的虚拟键也会亮。手机是双指操作：左手方向键，右手攻击 / 跳 / 旋风。

## 一局怎么走

1. **安全区营地**（森林最左边）：帐篷、篝火、商人豆豆。靠近商人按 `E` / 点「商店」买装备和药水；站在安全区里会缓慢回血，小怪不会进来。
2. **蘑菇森林**：小怪平时在出生点附近来回巡逻，**只有你靠近才追**（蘑菇 300px、幽灵 280px、树桩 460px 才吐种子）。
3. 击杀给经验、金币，偶尔掉鸡腿；左下角药水会自动喝（血量低于 45%，10 秒 CD）。
4. **传送门常驻**在森林尽头（x=3040），随时可以进，不用等杀满。
5. **蘑菇王巢穴**：独立地图，血月、暗红地面、没有杂兵，单挑蘑菇王：冲撞、跳砸落地冲击波、召唤小蘑菇。左侧有回程门。
6. 打死蘑菇王 → 结算 → 回城整备 → 下一局更强。

地图是分开的：野外只负责割草和成长，BOSS 图只负责单挑，中间用传送门衔接——和冒险岛的「野外地图 → BOSS 地图」一样。

## 血量与节奏

- 初始 200 血，BOSS 一下 34、小怪 12~18，站桩会被打死，必须躲冲击波。
- 升级 +16 血，护甲 +24 血，技能点 +14 血；药水一次回 50，10 秒 CD。

## 养成：本地存档

存档在 `localStorage` 的 `doudou-hero-save-v1`，**跨局保留**：

- **经验**累计成等级，重开时从存档等级起步；死了也保留本局收益。
- **金币捡到就入账**（不用等结算），在安全区商店或结算面板「回城整备」里花：
  - 武器 +5 攻，价格 `60 × 2^等级`，满 5 级
  - 护甲 +30 血，价格 `70 × 2^等级`，满 5 级
  - 药水 +1，25 金，上限 5
- **技能点**每升一级 +1，可点「+2 攻」或「+20 血」。
- 刷新页面、关掉浏览器再打开，进度都还在。
- 想从头开始：网址加 `?fresh=1`（会清档）。

## 从冒险岛搬过来的战斗骨架

- **横版卷轴 + 单向平台**：跳上平台、从平台下方穿过、空中追击。
- **三段连击**：每段前摇/后摇不同，第三段倍率最高、击退最大；空中攻击向下补判定。
- **命中反馈**：hitstop（命中停顿）、屏幕震动、伤害数字、暴击、击退、受击硬直。
- **受击无敌帧**：0.95 秒闪烁 + 击退，避免被怪群瞬间连死。
- **AOE 技能**：旋风斩持续 0.72 秒、每 0.13 秒判定一次，可以边转边走。
- **怪物分工**：走地追人 / 飞行穿墙 / 定点远程，逼玩家换站位。
- **BOSS 招式循环**：冲撞 → 跳砸（冲击波贴地，必须跳）→ 召唤，血量 45% 以下进入二阶段（更快）。
- **成长**：经验 → 等级 → 生命/攻击成长，越打越像割草。

## 文件

```
doudou-hero/
├── index.html   舞台、HUD、按钮、结算、竖屏提示
├── style.css    横屏 1280×720 布局（按钮和字号用 --u 跟随舞台缩放）
└── game.js      全部逻辑：物理、战斗、AI、BOSS、渲染、音效
```

调参集中在 `game.js` 顶部：`GROUND_Y`、`PLATFORMS`、`ENEMY`、`BOSS`、`ATTACK_*`、`TOTAL_KILLS`。
