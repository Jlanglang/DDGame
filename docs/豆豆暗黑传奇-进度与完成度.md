## 架构

```
data.js     表与常量（怪物 / 品级 / 掉落 / 房间 / 浮动概率）
core.js     随机 / 格子 / 装备区间属性 / 成长公式（纯函数）
world.js    主城 + 房间生成 / 碰撞 / 视野 / BFS   ← 换地图形态只改这里
combat.js   伤害（区间取值）/ 范围 / 目标 / 怪物行为 ← 调战斗只改这里
game.js     编排 + 6 个渲染层 + UI + 输入 + 存档
```

**替换成本**：换地图 → `world.js`；调战斗 → `combat.js`；调数值/掉落 → `data.js`。

## 本轮关键教训

- **品质不保证数值，只保证机会**：区间浮动比“品质给属性”更有期待感
- **保底保证“有东西”，词缀保证“有用”**：两件事分开
- **碾压只配给杂兵**：精英以上都要认真打，否则“回去刷低级”变成最优解
- **pauseAuto 必须有 resumeAuto**：只装关灯开关，灯就再也开不了
- **打怪不能越打越穷**：金币要覆盖药水，否则玩家先破产
