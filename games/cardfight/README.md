# 卡牌战斗（原型）

横屏 1280×720 的卡牌养成战斗架子：左我方 3 人、右敌方 3 个，固定站位，按号位自动普攻，怒气技能手动排队或开自动。

## 资产分工

| 目录 | 用途 |
|---|---|
| `faces/` | **英雄详情背景图**，864×1152 竖图，详情页全屏铺底；不是战斗立绘 |
| `4头身/` | 战斗立绘原图（Q 版全身，正面） |
| `cutouts/` | 战场用图：`*-6head.webp` 是当前英雄立绘，`monster-*.webp` 是怪物立绘；旧 `aurora.webp` 和 `monster-*.svg` 保留作回退 |

> `faces/` 里是英雄详情背景，不要拿去做战斗小立绘；战场立绘从 `4头身/` 出。

## 三层结构

1. **背景层**：`#bg` / `.layer-bg`，一张通用场景
2. **场景战斗层**：`#units` + `#fx`，立绘、攻击动画、伤害飘字、特效
3. **交互层**：`#detail` / `.layer-detail`，角色详情 / 装备 / 道具三个页签
